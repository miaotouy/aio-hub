# v0.7.0 实施领域调查结果与 RC 收口清单 (Desktop)

> 状态：RC 准备与发布审计
>

## 1. 审计范围与背景

本次审计针对 `0.7.0` 系列自 `alpha.1` 以来在桌面端落地的实际功能、架构重构、安全加固及已知问题修复进行全面盘点。剔除所有未落地的草案与探索性设计文档，聚焦于**已合入主干并具备运行态表现的实际代码交付**，作为转入 Release Candidate (`0.7.0-rc.1`) 的依据。

## 2. 核心实施领域落地清单

### 2.1. LLM 核心底座与服务层 (LLM Core & Infrastructure)

1. **凭证隔离与独立安全存储 (`src/utils/llm-secret/`)**
   - **存储混淆与隔离**：彻底将 API Key 从通用 Profile 配置文件中剥离，移入独立混淆存储机制（`storage.ts`, `codec.ts`）。
   - **哈希索引与状态管理**：建立密钥 SHA-256 哈希索引（`apiKeyHash.ts`）与生命周期状态表（`keyStates.ts`）。
   - **熔断与降级策略加固**：重构 Key 轮换与健康检查策略，修复“全部 Key 不可用时静默回退至首个坏 Key”的漏洞；全熔断时硬阻断并反馈冷却恢复时间。
   - **安全导入导出**：实现配置安全导出与导入（脱敏处理），严格规范 JSON 与 TOML 的解析边界。

2. **多协议适配与模型路由系统 (Routing & Adapters)**
   - **模型执行路由机制**：支持聚合渠道与模型执行路由的手工分配、探测结果持久化绑定与自动选择。
   - **信道诊断与探测**：新增渠道探测弹窗与服务，严格区分本地代理环境网络错误（端口/连通性）与上游服务商业务错误。
   - **协议与渠道拓展**：
     - 接入 TypeSafe AI System One 决策渠道支持。
     - 适配 OpenAI Responses 推理摘要结构与流式边界解析。
     - 接入本地 `audio.cpp` 音频服务渠道与专属 ASR/STT 端点。
     - 修复并对齐 Azure 渠道运行时、DeepSeek 思考控制与流式截断、Claude 自适应思考参数。

3. **模型元数据系统 v3 (Model Metadata v3)**
   - **规则核心分层**：完成 v3 规则核心落地与持久化存储改造，支持“用户自定义规则优先于渠道分组”的合并机制。
   - **全量内置目录自动更新**：内置元数据目录随版本升级自动应用，并提供覆盖分析视图、最终规则详情与刷新预览弹窗。
   - **主流模型生态收录**：收录并校准 DeepSeek V4/V4.1 (含多模态与视觉计费)、Claude 5 系列、GLM-5.2/5.3、Gemini 3 系列及数十种国产大模型的最新定价与能力参数。

### 2.2. 桌面核心工具与交互 (Desktop Tools)

#### 1. 聊天工作台 (`src/tools/llm-chat`)

- **草稿会话机制**：新增虚拟草稿会话流程，在首条消息发出前不持久化落盘，彻底解决历史列表产生空会话垃圾的问题。
- **消息生命周期与排队**：
  - 引入「等待中」生命周期状态与 UI 展示，支持并发分支排队与生成控制。
  - 完善持久化自愈：应用重启或崩溃恢复时，自动将残留的 `generating` 异常节点修复为 `complete` 或包含中断说明的 `error`。
- **斜杠指令系统 (Slash Commands)**：输入框支持 `/` 斜杠命令实时补全与执行引擎，与现有宏体系良好协同。
- **Token 预估精准化**：图片 Token 预估计入发送前的客户端缩放压缩，支持思考模型 Token 预留设置。
- **UI 与操作优化**：
  - 气泡模式重构悬浮式操作栏，消除常驻空位及边框裁切。
  - 支持单会话完整 JSON 导入与导出（含关联附件与上下文参数）。
  - 支持会话级自适应重试 HTTP 状态码白名单。
  - 接入后台 Agent 伴生分栏槽位，支持结构性让位。

#### 2. 后台任务与子智能体系统 (`src/tools/sub-agent` / `background-runtime`)

- **后台运行时 PoC 验证**：落地 `src/background-runtime` 与 Tauri 后台 JS 运行时 Bridge，验证执行脱离 UI 窗口的长效生命周期。
- **任务中心与可观测性 (Phase 1 ~ 3)**：
  - 交付任务中心面板（`BackgroundTaskCenter`），支持后台 Agent 运行调度、生命周期观测与状态查询。
  - 人工介入机制：支持任务中途追加指导叮嘱与紧急叫停中止。
  - 伴生视图：支持在右侧分栏中以只读模式透视后台任务的执行上下文。
  - 主会话协同：主会话工具消息内呈现派遣卡片、降级渲染、真实发送者标识与活动时间轴。

#### 3. Git 提交流程与代码分析 (`src/tools/git-committer`, `src/tools/git-analyzer`)

- **分支泳道与图谱可视化**：新增 Git 分支图谱与拓扑泳道渲染组件，直观展示分支分叉与合并流向。
- **完整右键菜单体系**：支持文件暂存/取消暂存、未跟踪文件显式区分「物理删除」与「放弃修改」、Diff 对比等原生交互。
- **全局工作区搜索**：新增工作区文件名称与文件内容全文快速检索（`useGitWorkspaceSearch`）。
- **媒体文件差异对比**：支持在差异视图中直接预览暂存与提交的图片/音频文件。
- **提示词与外观定制**：支持每个仓库配置独立的 AI 提交提示词模板、首选提交语言以及仓库个性化配色色盘。
- **提交流程优化**：改用 unified diff 替代整文件快照生成提交信息，自动剔除外层 Markdown 代码围栏；commitRange 统一调整为 1-based。

#### 4. 多媒体与音频处理

- **实时字幕与本地视频 OCR (`src/tools/realtime-subtitle-ocr`)**：
  - 推出**本地离线视频工作台**：支持双栏编辑器交互、视频播放与时间轴吸附、切片回放与结果校验。
  - 屏幕实时监控：支持监控区域原图与滤镜对比预览、行内编辑与自适应布局。
- **FFmpeg 视频工作台 (`src/tools/ffmpeg-tools`)**：
  - 引入积木式自定义参数作用域编辑。
  - 增加时间片段裁剪与关键帧吸附能力。
  - 单文件任务卡片支持结构化实时进度条与执行计划防覆盖保护。
- **批量色彩整理 (`src/tools/color-picker`)**：
  - 推出**批量图片色彩整理工具**：将海量图片色彩分析下沉至 Rust 后端并行处理。
  - 前端支持 1~4 档动态亮度阈值调节、圆盘点位最近邻色系分类与批量结果一键归档。

#### 5. 辅助工具与核心加固

- **本地文件操作器 (`src/tools/aio-file-operator`)**：
  - 新增复制、移动/重命名、文件元数据获取与递归搜索动作。
  - **安全报错截断**：针对模型误将数千字正文当路径传入导致报错上下文爆炸的问题，在沙箱拦截层实施字符截断与脱敏。
- **窗口自动化 (`src/tools/window-automator`)**：全线重构为中心坐标系，新增前台/后台双模式点击与键盘事件模拟。
- **分词计算器 (`src/tools/token-calculator`)**：分词器资产化（移除动态 JS 脚本加载），支持导入 TAR / TAR.GZ / ZIP 格式的 Hugging Face 分词模型。
- **富文本渲染器 (`src/tools/rich-text-renderer`)**：修复 VCP 围栏误解析与合并问题、图片失败自定义占位与资源名提示、接入 JEV 自然语言工具调用识别。
- **网页提炼 (`src/tools/web-distillery`)**：新增 Jina 云端提取模式与全局偏好设置。
- **符号链接迁移 (`src/tools/symlink-mover`)**：增加搬家前空间/权限预检与事务性回滚校验机制。

### 2.3. 系统平台与通用框架 (System & Platform)

1. **升级与迁移引导体系 (`src/flows/upgrade/`, `src/components/common/GuidedFlow/`)**
   - 提取了通用分步引导容器 `GuidedFlow`（点式进度指示、步骤边界隔离）。
   - 升级面板重构：版本说明转为运行时动态读取，支持历史版本档案浏览与检索；知识库迁移等多步骤平滑收敛为至多 5 步引导。
2. **Windows NSIS 安装程序定制 (`src-tauri/nsis/`)**
   - 引入自定义 NSIS 模板，支持用户在安装时自定义数据存储目录。
   - 覆盖安装/重新安装时自动识别并展示当前已安装版本与待安装版本信息。
3. **主页与全局外观 (`src/views/Home/`, 主题系统)**
   - 主页重构成网格门户化布局，支持最近打开工具统计与快捷卡片拖拽排序。
   - 引入顶部轻量浮动消息（`TopMessageHost`），减少强阻断弹窗打扰。
   - 新增趣味 Doodle 彩蛋机制，壁纸主题色提取新增语义色相避碰保护。

## 4. 0.7.0-RC 发布前收口与检查清单 (Release Gate)

在将版本提升至 `0.7.0-rc.1` 并最终发布前，需依序执行以下收口验证：

### 阶段一：编译与工程（必须全绿）

- [ ] **前端类型检查**：`bun run type-check`（确保无 TypeScript 类型错误）
- [ ] **生产构建验证**：`bun run build`（覆盖 Vite 打包、动态导入分包、CSS 及静态资源引用）
- [ ] **Rust 后端编译**：`cd src-tauri && cargo check`（验证所有 Tauri commands 宏与模块签名）
- [ ] **核心单元测试**：
  - `bun test src/utils/llm-secret/`（验证 Key 混淆与状态迁移）
  - `bun test src/config/__tests__/model-metadata.test.ts`（验证元数据规则）
  - `bun test src/tools/llm-chat/stores/session/`（验证会话原子保存与自愈）
  - `bun test src/tools/aio-file-operator/`（验证文件沙箱与截断）

### 阶段二：运行时与数据平滑迁移核对

- [ ] **旧版本平滑升级**：使用 `v0.6.6` / 早期版本的数据目录启动，确认老配置能够自动迁入 `llm-secret` 混淆存储。
- [ ] **GuidedFlow 引导体验**：检查新安装与版本升级时弹出的引导流弹窗（Release Notes 与可能存在的数据迁移步骤），确保不超过 5 步且点式导航无回退 Bug。
- [x] **Windows NSIS 安装测试**：打出 Windows 安装包，测试“自定义安装路径”和“覆盖安装版本回显”是否正常。

### 阶段三：版本号与更新文档同步

- [ ] **版本号统一提升**：执行 `bun run version:set -- desktop 0.7.0-rc.1`，并使用 `bun run version:check` 校验桌面配置一致性。
- [ ] **版本更新日志归档**：在 `src/flows/upgrade/releases/` 下补齐 `v0.7.0-rc.1.md` / `ts` 档案，完整列出本次大版本的核心新增功能与修复项。
