# 正式版本机控制架构

## 入口与生命周期

- 前端：`src/services/agent-control/`，桌面挂载后订阅受控请求，向宿主报告就绪；浏览器降级模式沿用页面自身行为。
- Electron：`electron/agent-control.ts`，由主进程管理本地 Socket、窗口转发、请求限额与退出清理。
- Tauri：`src-tauri/src/commands/agent_control.rs`，应用 setup 注册状态，插件退出钩子停止监听与移除发现文件；对应命令注册在 `src-tauri/src/commands.rs`。
- CLI：`scripts/agent-control/cli.ts`，`bun run control` 直接调用，`control:build` 输出可独立复制的单文件模块。
- 设置：日志与诊断中的“本机调试接管”，持久化于宿主数据根目录的 `control-settings.json`。宿主在创建业务窗口前读取，默认关闭；持久化由宿主负责，以支持窗口加载前启动监听。

控制入口与现有 Dev Control 独立。发布资源通过正常平台适配器调用生产命令，开发实例继续使用原有隔离目录和协议。

## 本机协议

每条连接收发一条 NDJSON。请求包括 `token`、目标 `window` 和 `command`；宿主为内部转发生成独立请求 ID，并验证回复来自目标窗口。发现文件记录协议版本、宿主、PID、端点、随机 Token 与数据目录，CLI 展示时剥离 Token。

- Windows 使用随机名称的 Named Pipe；Unix 使用当前用户目录中的 Socket，并设置目录 `0700`、Socket 与连接文件 `0600`。
- 每个宿主最多接纳 16 条连接，同时执行一条前端指令。
- 请求上限 256 KiB，回复上限 4 MiB；宿主执行等待 15 秒，连接最长 17 秒，CLI 等待 18 秒。
- 关闭通道取消待处理回复并断开连接。重新开启生成新的端点和 Token；异常退出遗留的发现文件通过 CLI 进程/连接检查跳过。
- 前端操作在副作用前检查有效期与取消信号；已开始的业务任务按既有任务生命周期处理。

`state` 输出应用就绪、内部路由、视口和记录状态。`windows` 由宿主直接返回。`observe`、`inspect`、界面操作、导航、记录读取与工具动作交由指定窗口执行。

## DOM 与输出

页面内引擎沿用 Dev Control 的 DOM 定位、可见性、原生输入 setter 和事件语义，并针对生产观察单独维护严格的文本读取路径。`ref` 与快照、元素身份及语义绑定，60 秒过期；CSS 适用于唯一目标和几何排查。观察和检查保持滚动位置，点击与输入才会定位到可操作位置。

Element Plus 的开关、单选/复选框通过可见包装元素提供语义和 checked 状态；Teleport 弹层由整份 document 的观察覆盖。命中检测拒绝被遮挡的输入目标。

文本读取逐子树跳过 `data-sensitive`、`data-control-ignore`、表单值和可编辑区域。状态/元数据经过统一输出脱敏；工具同步动作仅回执行确认，异步动作复用原任务系统返回任务身份。业务错误转为稳定错误码与可行动提示，避免原始响应正文进入 CLI。

工具动作直接桥接 `toolRegistryManager`，方法必须显式标记 `agentCallable: true`。同步调用保留工具 `this`、标准参数对象和取消上下文；异步方法复用 `taskManager.submitTask()`。配置查询仍通过对应工具界面观察。

## 布局现场

接管开启后，记录器每 125ms 检查聊天会话列表、虚拟行和消息区的几何变化。稳定样本去重，输入事件限频，环形缓冲最多 600 条。记录内容为尺寸、位置、索引、元素临时身份、事件类型和时间。

缓冲每两秒及页面隐藏时写入当前窗口 sessionStorage，刷新后恢复；快捷键与手动导出先复制现场再执行文件操作。快捷键保存路径由 `getAppConfigDir()` 解析，设置页支持选择文件；CLI 导出额外包含当时的语义观察。所有产物由用户主动保存，普通关闭开关清理当前临时缓冲。
