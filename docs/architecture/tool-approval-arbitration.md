# 工具自动审批仲裁

## 执行链路

工具执行器先检查工具自身的安全策略，再检查静态自动批准配置。需要审批的请求统一进入 `toolCallingStore.requestApproval()`，由注入的仲裁器返回批准、拒绝或升级人工。聊天和后台子任务共用此入口。

全局决策渠道保存审批引擎、渠道、模型、超时与重试配置；智能体保存启用状态、保守灰区或激进策略，以及 JEV 的概率阈值。历史渠道配置经默认值合并后继续使用 JEV。

## 配置入口

审批模型在「智能体设置 → 工具调用 → AI 自动审批」中配置。智能体管理和 Chat 内的智能体设置共用 `ToolCallingSection`，模型配置组件归属 `tool-calling` 模块。工具调用页默认展示「工具配置」页签，审批模型与策略集中在「AI 自动审批」页签；切换页签保留当前编辑状态。

- **全局模型配置**：审批引擎、渠道与模型、审核超时和补充审批规则由所有启用自动审批的智能体共用，点击「保存审批模型配置」后立即生效。
- **智能体审批策略**：启用状态、仲裁策略、JEV 阈值和外部来源策略随当前智能体保存。
- **渠道管理**：「AI 服务配置」负责渠道连接和模型元数据；审批模型选择器复用其中已启用的渠道与模型。

## 两种审批引擎

### JEV

通过 System One 问答接口获取风险、意图与裁决概率，继续使用既有问卷和阈值判定。

### 普通 LLM

宿主通过 `useLlmRequest().sendRequest()` 注入调用能力，仲裁服务保持与 Pinia 解耦。文本模型使用独立系统提示词，用户意图、工具说明和实际执行参数作为 JSON 数据消息发送。结构化凭证字段与二进制载荷在发送前脱敏。

裁决 JSON 包含：

| 字段                 | 含义                           |
| -------------------- | ------------------------------ |
| action               | approve / deny / escalate      |
| riskLevel            | low / medium / high            |
| matchesUserIntent    | 操作和范围是否符合用户意图     |
| explicitlyAuthorized | 用户是否明确授权具体操作和范围 |
| reason               | 简短裁决原因                   |

解析要求完整字段、严格枚举和布尔类型。仅低风险且意图一致的批准可执行；激进模式中的强制审批还要求明确授权。缺少上下文、上下文超过 16,000 字符、响应格式异常和判断矛盾均升级人工。LLM 使用离散风险等级，JEV 继续使用概率阈值。

有 JSON 输出能力标记的模型使用 JSON 输出模式，其余文本模型按提示词输出并接受同样的严格解析。审核请求使用非流式响应，单次输出上限为 2,048 tokens。

## 共用约束

- 工具禁止策略先于审批仲裁；静态危险特征直接转人工。
- 保守灰区中的强制审批直接转人工。
- 并发上限、请求指纹去重、总超时预算与有限网络重试由同一仲裁服务管理。
- 调用方取消后，迟到的模型批准结果保持取消路径。
- 外部来源的自动批准由显式配置约束；缺少智能体绑定的 VCP 请求仍按既有人工审批链处理。
- 渠道故障转人工，审批引擎由用户显式选择。

## 实际执行上下文

执行器完成默认值合并和类型转换后，把 `effectiveArgs` 与方法说明传入审批入口。危险特征检查、请求指纹和两种模型上下文均使用实际执行参数。

用户意图沿请求所属会话的活动分支读取，跳过停用和空白消息。JEV 沿用 400 字符摘要；LLM 在完整上下文预算内读取更长指令，超预算转人工。

## 审计与展示

最终来源包括规则、JEV、LLM、人工、超时和取消。模型快照保存引擎、动作、原因、模型与耗时；LLM 另存离散风险和授权判断。

升级人工后，最终来源随人工操作更新，之前的模型证据继续保留。后台任务将引擎、模型动作、离散风险及原因写入任务快照。旧记录的 `jevAction` 继续兼容读取。

消息卡片、审批条和任务详情按同一展示判定区分 JEV 与 LLM。LLM 显示离散风险与原因，JEV 显示有效概率值。

## 实现入口

- `src/tools/tool-calling/components/ApprovalModelSettings.vue`：全局审批模型配置 UI。
- `src/tools/agent-manager/components/agent-editor/sections/ToolCallingSection.vue`：智能体管理与 Chat 共用的工具审批设置入口。
- `src/services/decision-arbiter/index.ts`：公共仲裁流程与引擎分流。
- `src/services/decision-arbiter/llmApproval.ts`：普通 LLM 请求、解析与裁决。
- `src/tools/llm-chat/composables/chat/setupApprovalArbiter.ts`：宿主装配和会话意图读取。
- `src/tools/llm-chat/stores/toolCallingStore.ts`：审批状态、人工接管与任务结算。
- `src/services/background-tasks/approvalBridge.ts`：后台任务持久化审计。
