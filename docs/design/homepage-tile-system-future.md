## 核心构想

工具不再只是"一个可点击的图标卡片"，而是可以提供自己的**磁贴组件（Widget）**，在主页上展示实时内容或快捷操作。用户可以像 Windows 磁贴或 iOS 小组件那样，自由拖拽、调整尺寸、添加或删除磁贴。

---

## 磁贴尺寸规格（参考）

| 尺寸 | 格子占用 | 适用场景               |
| ---- | -------- | ---------------------- |
| 1×1  | 小       | 快速启动、单一状态指示 |
| 2×2  | 中       | 迷你对话框、缩略图预览 |
| 4×2  | 大       | 图表、多会话列表       |

---

## 各工具磁贴设想

- **LLM Chat**：展示最近的对话会话列表，或内嵌一个迷你快捷对话框。
- **Media Generator**：展示最近生成的图片缩略图网格。
- **System Pulse**（假设存在）：实时 CPU/内存占用的迷你折线图。
- **Service Monitor**（假设存在）：当前本地服务的健康状态指示灯。

---

## 前置依赖

在正式实施磁贴系统前，需要先有：

1. **工具插件化协议**：工具需要能以标准接口导出自己的 Widget 组件，主页按需动态加载，而不是硬编码。
2. **布局持久化**：拖拽结果、尺寸配置需要落盘到 `ConfigManager`，不能用 localStorage。
3. **主页配置体系**：当前主页重构完成后，配置结构（推荐位、最近使用）迁移到 `ConfigManager` 后，再在此基础上扩展磁贴布局配置。

---

## 与当前重构的关系

当前正在实施的主页重构（快速入口横条 + 垂直分类侧边栏）**不需要**为磁贴系统预留任何代码结构。等到需要做磁贴时再按实际情况设计，不要提前抽象。
