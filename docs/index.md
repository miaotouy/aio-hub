  - title: 可配置的上下文
    details: 按任务组合上下文处理器、动态宏、正则规则、知识检索和压缩策略，并查看最终发送给模型的内容。

  - title: 插件与服务扩展
    details: 通过 JS、Native 和 Sidecar 插件扩展功能，结合 Agent Skills、VCP 连接器和已注册服务组织工作流。
  - title: 本地与云端服务
    details: 在本地保存配置和资产，按需连接本地模型、远程 AI 服务及网页提取引擎，为不同任务选择合适的处理方式。
