## 发布材料说明

- 用户正文按模块分节，以功能条目说明变化、用途与升级注意事项；Alpha 阶段说明同步采用该结构，提交索引保留在本文供开发追溯。编写约定见 [releases/AGENTS.md](../../src/flows/upgrade/releases/AGENTS.md)。
- 移动端按独立版本发布，相关提交在下方索引中保留；桌面版正文聚焦桌面能力与共享能力。
- Electron 迁移等设计方案和后台运行时 PoC 按其当前状态处理，正式能力以实际工具与运行入口为准。
- 旧版思绪备份到 Knowledge 的转换为单向转换。Alpha 1 档案中原有的“可逆”表述已修正，Alpha 1 与本次累计说明均提醒保留原始备份。
- 当前 `.github/workflows/build.yml` 使用最近可达 tag 生成提交记录；对本次目标执行 `git describe --tags --abbrev=0 v0.7.0-r.1^` 会得到 `v0.7.0-alpha.6`。发布本次版本时应使用这里的累计正文和上次实际发布基线。本次整理保留现有 CI 配置。
- 统计固定到上述两个 tag；本次新增的说明文件属于后续工作区修改。
