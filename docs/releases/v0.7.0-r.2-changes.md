## 实现与兼容说明

### 预设消息组合

- 新增共享包 `@aiohub/agent-preset-core`，统一正文校验、编译、克隆、转换、导入兼容与结构撤销。
- 最终结构采用有序片段，每个片段保存版本列表、当前版本及启用状态。编译时先以连接符拼接宿主正文，再处理宏；片段沿用宿主消息的角色与注入位置。
- 两端支持片段和版本命名、排序、选择及完整正文预览。批量管理通过当前选择生成摘要，结构错误时提示修正。
- 桌面编辑增加草稿离开确认、保存冲突检查和串行持久化；结构撤销与正文编辑器自身的撤销分别处理。
- 含组合正文的智能体导出格式升级为文件版本 2，正文结构版本为 1，并声明 `preset-composition-v1` 能力；普通正文沿用既有导入兼容。
- 详见[智能体管理架构](../../src/tools/agent-manager/ARCHITECTURE.md#消息内部组合)。

### 聊天编辑与数据保护

- 消息工具栏的布局和展开状态保存到 UI 偏好，并同步到分离窗口；动作可用条件由统一定义提供。
- 高级编辑的分支保存复用既有分支流程，保留完整编辑字段、节点身份与父子关系保护，清理新分支运行态，支持单步撤销和重做。
- 文件重载按磁盘修订恢复会话，更新消息树和列表索引，保留选择与收藏并重建撤销记录；生成、排队、写入和并发编辑期间有操作保护。
- 物理布局的尺寸更新保留当前位置与仿真状态，重新构建时沿用速度及根节点锚点，显式重置继续执行重新布局。

### 富文本修复与性能记录

- 本轮补充 CommonMark 对照、GFM 与项目扩展语料、静态与流式完成态一致性用例，以及解析、流式、内存和真实 Tauri 采样工具。
- 解析修复覆盖围栏边界、列表归属及编号、引用标题、实体与 HTML 空格、表格空格和空列等具体行为。列表增量更新保留未变化条目对象与 ID，渲染层按节点及上下文复用子树。
- 已提交的专项记录中，100 KiB 列表的流式更新等待 P95 为 **294.0 → 95.4 ms**，帧间隔 P95 为 **111.6 → 15.6 ms**；普通混排第三次卸载并 GC 后，主线程堆为 **78.11 → 46.16 MiB**。这些数值来自对应专项场景，反映局部优化效果。
- 性能数据沿用历史采样记录，本次文档整理仅核对来源。样本、运行条件、指标范围及剩余优化空间见[规范对照与性能记录](../../src/tools/rich-text-renderer/docs/Plan/markdown-conformance-and-performance.md)。
- 当前仍保留任务列表复选框、代码单元格转义管道符等兼容差异，范围详见[Markdown 语法契约](../../src/tools/rich-text-renderer/docs/markdown-syntax-contract.md)。

### Git 分析与媒体生成边界

- GitHub 数据源读取公开仓库，采用匿名请求和远端只读模式，错误提示覆盖匿名额度耗尽。工程指标明确显示行数、文件明细的加载覆盖范围。
- AI 洞察使用当前筛选结果和所选模型，输入受提交数量与单条消息长度限制；仓库元数据作为分析材料传入。
- 媒体生成参考图输入上限调整为 16 张，统一检查重复项与上限；具体请求遵循模型自身能力。优化图片开关同时受视觉能力和翻译模式约束。
- 转写场景的输出上限改用独立常量 `65536`，与通用参数输入上限解耦，属于配置维护。
