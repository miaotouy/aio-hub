# 关于与许可

在「设置 → 关于」中可以查看当前版本、选择更新通道、安装更新和阅读版本说明。

## 版本与更新通道

页面顶部显示当前安装的应用名称与版本。更新通道可以手动切换：

| 通道         | 适用情况                                              |
| ------------ | ----------------------------------------------------- |
| **稳定版**   | 获取正式发布版本，支持可用更新包的应用内安装          |
| **预发布版** | 获取 Alpha、Beta、RC 等预览版本，部分版本需要手动下载 |

默认通道根据当前安装版本判断：预发布版本默认使用预发布通道，正式版本默认使用稳定通道。手动选择后，应用会保存你的偏好。

## 检查和安装更新

1. 选择需要的更新通道。
2. 点击版本号旁的「检查更新」。
3. 有新版本时，阅读弹窗中的版本号与更新说明。
4. 根据弹窗提供的操作安装更新。

| 操作         | 后续过程                                                   |
| ------------ | ---------------------------------------------------------- |
| **立即更新** | 下载并安装更新包，完成后重启应用；弹窗会显示下载和安装状态 |
| **前往下载** | 在浏览器中打开发布页面，手动下载适合当前平台的安装包       |

开始安装前先保存正在编辑的内容。手动覆盖安装时沿用已有数据目录；迁移机器或更换数据位置时，先参考 [安装指南](../installation.md) 和 [配置管理](./general-startup.md#配置管理)。

### 检查失败时

- 确认当前网络能够访问更新服务，按需要检查应用的代理设置。
- 应用内安装失败时，可改为从 GitHub Releases 下载对应平台的安装包。
- 预览版和正式版的发布进度可能不同，核对当前选择的更新通道。

按住 **Alt** 再点击「检查更新」可以请求显示版本弹窗，用于查看返回的版本说明。

## 版本说明与升级事项

「版本说明」入口用于阅读应用内提供的历史版本说明。存在尚待完成的升级操作时，可通过「继续升级事项」返回升级流程，例如完成数据迁移。

检查更新弹窗中的发布说明与应用内的历史版本说明有各自的入口，可按需要查看。

## 项目信息与支持

关于页面提供项目仓库、开发者和许可信息，以及 GitHub Star、爱发电等支持入口。问题反馈和功能建议可提交到 [GitHub Issues](https://github.com/miaotouy/aio-hub/issues)，开发约定见 [贡献指南](../../guide/contribution-guide.md)。
