# AI 模型元数据配置

模型元数据规则用于为模型补充图标、分组、能力、上下文长度、分词器、请求家族和媒体生成参数。规则本身是**目录**；已保存模型会在创建、导入、刷新或手动应用预设时获得一份自己的元数据快照。

## 入口

1. 打开设置。
2. 在左侧选择 **AI 模型元数据配置**。

## 规则与模型的关系

- **内置规则**：随应用版本提供的目录，应用升级后会**自动更新**（新增、修改、删除都会生效）。
- **内置已修改**：你对某条内置规则的本地覆盖；应用升级不会覆盖它，可在规则卡片中恢复内置值。
- **自定义规则**：完全由你创建和维护的规则，不会随目录更新改变。
- **已保存模型**：运行时优先读取模型对象自身的字段，不会因你修改规则目录而静默改变；需要同步时用“刷新模型配置”显式执行。

规则支持 `Provider`、精确模型、模型前缀、模型包含和正则表达式匹配。多条规则命中时按优先级合并；数组字段整体替换，`exclusive` 规则可截断更低优先级规则。

## 常用操作

| 操作                       | 说明                                                                                   |
| -------------------------- | -------------------------------------------------------------------------------------- |
| 添加、编辑、启用或删除规则 | 管理内置覆盖和自定义规则。删除内置规则只会抑制该规则，不会删除你的模型。               |
| 恢复内置规则               | 移除该规则的本地覆盖或屏蔽，重新采用当前应用版本的内置规则。                           |
| 刷新模型配置               | 单独预览并选择 `跟随目录` 模式模型的受管字段变更；目录更新本身不会刷新模型。           |
| 导入配置                   | 先解析、迁移和展示诊断；存在阻塞诊断时不能确认写入。                                   |
| 导出配置                   | 导出当前 v3 分层规则存储，便于备份或迁移。                                             |

内置目录随应用版本自动更新，因此不需要手动处理目录更新：未被你改动的内置规则会随版本变化；你改过或删除过的内置规则保持不变。

## 刷新模型时会发生什么

1. 内置目录已随应用版本自动更新，无需手动处理。
2. 点击 **刷新模型配置** 查看会变化的模型和字段。
3. 只勾选需要刷新、且绑定模式为“跟随目录”的模型。
4. 确认后按渠道保存；如果部分渠道保存失败，提示会列出失败渠道，未成功的数据可检查渠道配置后重试。

手动模式模型不会被规则写入；“填补缺失”模式只在模型缺少字段时补齐。媒体生成参数一旦写入模型，也由模型自身持有，媒体生成运行时不会回退到全局规则。

## 测试模式

输入模型 ID 和可选 Provider，可以查看命中的规则、图标、分组与候选规则。这是编辑目录时的分析工具，不会修改任何已保存模型。

## 移动端

移动端使用与桌面端相同的 v3 规则、迁移、目录同步和物化核心。新增渠道预设、从 API 添加模型以及手动新增模型时会写入匹配后的模型快照；之后模型列表、选择器和请求家族判断读取该模型快照。
