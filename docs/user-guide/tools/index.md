# 工具总览

AIO Hub 的工具覆盖 AI 对话、资料检索、媒体创作、文件处理和开发调试。在主页查找工具名称即可打开；常用工具可以固定到侧边栏，支持独立窗口的工具还可以分离使用。

下表按用途列出工具。带链接的名称可直接进入教程；其余工具可先通过功能说明在应用中查找。

## 对话、知识与 AI 创作

| 工具                                               | 可以做什么                                                       |
| -------------------------------------------------- | ---------------------------------------------------------------- |
| [LLM 对话](./llm-chat/index.md)                    | 管理多会话和树状分支，组合世界书、附件、上下文处理器与工具调用   |
| [智能体大厅](./llm-chat/agents/index.md)           | 创建、导入和配置智能体，管理私有资产与世界书，选择智能体开始对话 |
| [用户档案中心](./llm-chat/agents/user-profiles.md) | 管理对话中的用户身份、自定义样式、正则管道和默认档案             |
| [ST 世界书管理器](./st-worldbook-editor.md)        | 导入、编辑和维护 SillyTavern 世界书及条目                        |
| [知识资料库](./knowledge-base/index.md)            | 导入资料、建立索引、管理知识条目，并为智能体提供检索内容         |
| 思绪                                               | 管理结构化知识与记忆，使用向量和标签检索，供智能体调用           |
| 翻译工作台                                         | 使用多个预设和模型渠道并行翻译，对比译文                         |
| 技能管理                                           | 浏览、安装、启用和禁用 Agent Skills                              |
| [媒体生成中心](./media-generator/index.md)         | 配置模型与生成参数，管理图片、视频、音频等生成任务及结果         |
| [Web Canvas](./web-canvas/index.md)                | 在画布中组织文件与智能体协作，编辑内容并结合 Git 管理版本        |
| [网页蒸馏室](./web-distillery.md)                  | 搜索网页，选择本地或云端引擎提取正文，管理站点配方与身份         |
| [智能 OCR](./smart-ocr/index.md)                   | 选择本地、视觉模型或云端 OCR 引擎，识别图片和长图文字            |
| [实时字幕 OCR](./realtime-subtitle-ocr/index.md)   | 识别屏幕字幕，或在本地视频工作台中完成离线识别与字幕整理         |
| [多模态转写](./transcription.md)                   | 将图片、音频、视频和 PDF 转为可用于文本模型的内容                |

- **第一次使用 AI 对话**：[快速开始](../getting-started.md) → [智能体配置](./llm-chat/agents/editor-guide.md) → [消息与分支](./llm-chat/messages/index.md)。
- **整理网页和文档**：[网页蒸馏室](./web-distillery.md) → [资产管理器](./asset-manager/index.md) → [知识库索引](./knowledge-base/indexing.md)。
- **处理图片和视频**：[智能 OCR](./smart-ocr/index.md)、[本地视频字幕识别](./realtime-subtitle-ocr/index.md)、[FFmpeg 工具](./ffmpeg-tools.md)。
- **让智能体使用工具**：[工具调用](./llm-chat/tool-calling/index.md) → [审批策略](./llm-chat/tool-calling/approval-strategy.md) → [执行与调试](./llm-chat/tool-calling/execution-debug.md)。

工具的具体可用能力取决于当前平台、已配置的模型渠道和本机依赖。窗口与侧边栏操作见 [工作区基础](../workspace-basics.md)。
