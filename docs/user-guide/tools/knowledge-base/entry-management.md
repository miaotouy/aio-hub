# 文档与来源管理

Knowledge 的管理单元是文档，不是 CAIU 或思绪条目。每个文档保留来源路径、标题、MIME 类型、大小、checksum 和更新时间，并派生出可重建的 chunk、FTS、vector 与 graph edge。

## 文档列表

“文档”模式支持按标题和来源路径筛选。每行显示：

- 文档标题
- 分块数量
- 文件大小
- 完整来源路径

选择文档后，右侧会读取当前数据库中的实际分块。

## 更新文档

`sourcePath` 是同一资料库内的稳定来源键。再次导入同一路径时，系统会在事务中替换文档内容和全部派生索引，避免新旧分块混用。

如果文件移动到了新路径，当前版本会把它识别为新来源。目录同步与来源重定位尚未提供产品化入口。

## 删除文档

删除需要确认。操作会同步移除：

- document 记录
- chunk 记录
- FTS 条目
- chunk vector
- 相邻 chunk graph edge

删除不可撤销，需要恢复时请重新导入源文件。

## 重建分块索引

资料库菜单中的“重建分块索引”会重新切分全部文档，并清除现有语义向量配置。适用于切分规则变化或索引修复。

重建完成后：

- 关键词检索立即可用。
- 语义覆盖率归零。
- 需要再次执行“语义索引”。

## 当前不包含的能力

第一阶段没有文件夹 watcher、持久化 ingest queue、文档在线编辑和来源重定位。这些能力需要和目录稳定性检查、任务恢复及失败检查器一起实现，不能仅增加一个文件监听开关。
