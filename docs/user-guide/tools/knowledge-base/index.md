# 知识资料库快速上手

知识资料库用于导入 PDF、DOCX、HTML、Markdown、文本和代码文件，并把它们转换为带来源信息的文档分块。它与“思绪”是两个独立领域：知识资料库管理可引用的 document/chunk/source，思绪管理完整语义条目、标签和联想召回。

## 处理旧知识库数据迁移

升级后如果检测到旧 `knowledge/bases`、`vectors` 或 `tag_pool` 目录，应用只会显示待迁移提示，不会在启动时自动改写用户数据。可以从版本升级引导、“设置 → 关于 → 继续升级事项”或知识资料库顶部提示进入迁移流程。

迁移流程会依次展示旧数据规模、可保留字段、待重建内容和备份提示。只有同时确认备份与写入风险后，应用才会把旧 Recall 集合写入新的 SQLite 存储。迁移报告会分别显示主数据、向量、待重建项和问题明细。

旧目录默认保留。只有主数据和向量均完整通过、没有待重建向量和未解决问题时，流程才提供独立清理选项；清理前还需要再次输入 `DELETE` 确认。迁移中断或主数据部分成功时，可以关闭流程稍后继续，同一来源指纹不会重复导入已完成内容。

## 创建资料库

1. 打开“知识资料库”。
2. 点击侧栏右上角的加号。
3. 输入资料库名称，可补充用途说明。
4. 点击“创建”。

创建成功后会自动进入新资料库。

## 导入文档

点击顶部“导入文档”，可一次选择多个支持的文件。界面会分别显示解析进度和写入进度。

- 单个文件失败不会中断整批导入。
- 成功项会立即保留。
- 失败数量会在工作台顶部汇总，可重新选择失败文件重试。
- 再次导入相同来源路径会更新原文档及其分块。

## 检查文档分块

“文档”模式左侧显示当前资料库的文档列表。选择文档后，右侧展示实际进入索引的分块、章节标题和分块编号。

这不是原文件预览，而是检索引擎实际读取的文本。检索效果异常时，应先在这里检查解析和切分结果。

## 构建语义索引

文档导入后，关键词索引立即可用。需要语义或混合检索时：

1. 点击顶部“语义索引”。
2. 选择一个已启用且支持 Embedding 的模型。
3. 点击“开始构建”。
4. 等待分块覆盖率达到 100%。

切换模型会要求确认。界面按当前模型显示向量覆盖率；已写入批次会被保留，失败后可以重新构建。

## 测试检索

切换到“检索测试”模式，输入查询并选择策略：

| 策略   | 说明                                               |
| ------ | -------------------------------------------------- |
| 自动   | 有可用查询向量时使用混合检索，否则退化为关键词检索 |
| 关键词 | 只使用 BM25，导入后立即可用                        |
| 混合   | 融合关键词、向量和相邻分块信号                     |
| 语义   | 只使用当前模型的向量                               |

结果详情显示来源路径、章节、分块编号和命中信号。点击“查看文档”可回到文档模式并定位来源。

## 在 Agent 中使用

Agent 通过稳定的资料库 ID 获得 Knowledge 资料访问权限。授权本身不会自动检索，也不会自动向每轮上下文注入目录；需要常驻目录时，可在合适的预设消息位置放置 `{{knowledge_list}}`。具体权限和调用方式见 [Agent 集成](./agent-integration.md)。
