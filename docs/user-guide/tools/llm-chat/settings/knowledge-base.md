# <LIcon name="RecallIcon" size="28" /> 思绪设置

思绪设置展示思绪（向量检索）当前使用的 Embedding 模型，并提供前往思绪工具修改配置的入口。

## 模型关联

- **当前 Embedding 模型**:
  - 显示思绪工具中配置的默认向量化模型。
  - **重要性**: 思绪条目向量化时都会通过此模型转换为向量。检索时，用户的提问也会使用同一模型进行向量化以匹配内容，所有智能体的思绪集检索都使用此模型。
  - **快速跳转**: 点击 **“前往思绪配置 →”** 可直接进入思绪工具更改模型。

## 性能与缓存管理

缓存容量在思绪工具的设置中调整，系统采用了双层缓存机制：

- **向量缓存容量 (Embedding Cache)**:
  - **位置**: 「向量化 (Embedding) 配置」分区。
  - **作用**: 控制保留的文本片段向量数量。较大的值能显著减少对 Embedding API 的重复调用（尤其是在多轮对话中），但会增加内存占用。
- **检索结果缓存容量 (Retrieval Cache)**:
  - **位置**: 「检索与索引策略」分区。
  - **作用**: 控制完整检索结果（Top-K 匹配块）的缓存数量，所有会话与工具共用，按 LRU 策略淘汰。当你在短时间内提出相似问题时，系统可直接从缓存返回结果，无需重新进行复杂的向量空间计算。

---

::: warning 注意
**模型一致性**: 如果你在思绪工具中更换了 Embedding 模型，务必对已有的思绪条目重新向量化，否则检索将因向量维度或空间分布不一致而失效。
:::
