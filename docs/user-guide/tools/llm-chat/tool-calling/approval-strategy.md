# 审批策略与交互

工具调用先经过工具自身的安全策略检查，再根据智能体的执行模式、自动批准列表和决策仲裁设置决定是否执行。

## 执行模式与自动批准列表

在智能体编辑器的“工具调用”面板中选择执行模式：

- **自动模式**：自动批准列表中的工具或方法可直接执行，其余请求进入审批流程。
- **手动模式**：所有工具调用都进入审批流程，适合需要逐项确认的场景。

工具自身的禁止策略会直接拦截调用；强制审批策略优先于自动批准列表。

## AI 自动审批

在“设置 → AI 服务配置”中选择审批模型类型、决策渠道和审核超时，点击“保存”；再在智能体的“工具调用”面板中开启“AI 自动审批”。所有智能体共用全局审批模型，开关和策略按智能体设置。

审批模型类型有两种：

- **JEV 决策模型**：使用专用决策接口，结合风险、意图和置信度阈值判断。
- **普通 LLM**：使用已配置的文本模型，按低、中、高风险和用户授权情况判断。可填写补充审批规则，例如限定工作目录、要求覆盖已有文件前人工确认。

开启后，进入审批流程的请求会先接受模型审核：

- **低风险且符合用户意图**：自动批准。
- **高风险**：自动拒绝。
- **信息不足、判断不确定或渠道调用失败**：转人工审批。

审核使用请求所属会话活动分支上的最近一条有效用户消息作为意图参考，并核对工具说明与实际执行参数。子智能体按自身配置参与审核。

可选择两种仲裁策略：

- **保守灰区**：工具要求强制审批时直接转人工，推荐日常使用。
- **激进模式**：强制审批请求也可参与审核。JEV 使用更严格的风险阈值；普通 LLM 要求低风险、符合用户意图且用户已明确授权。

命中静态危险特征的调用会转人工处理。JEV 的风险、意图和置信度阈值可在智能体面板中调整。普通 LLM 遇到上下文缺失、内容过长、回复格式异常或判断矛盾时转人工确认。

## 审批交互

审核期间，工具消息显示“等待 AI 审核”；需要人工处理时，聊天界面底部显示审批栏：

- **参数预览**：点击工具名称查看调用参数。
- **单条批准**：执行该次调用。
- **拒绝**：向模型反馈该操作已被拒绝，供其调整后续步骤。
- **全部批准**：一次处理当前待批准的多个请求。

经过模型仲裁的请求会展示裁决建议与原因。后台任务等待人工处理时，也可从任务中心进入对应审批操作。

## 工具与方法设置

智能体配置支持以下控制：

- **工具开关**：控制整个工具是否可用。
- **方法开关**：按方法控制，例如允许读取文件、关闭写入文件。
- **自动批准勾选**：为常用且安全的查询操作设置自动批准。
