# 审批策略与交互

工具调用先经过工具自身的安全策略检查，再根据智能体的执行模式、自动批准列表和决策仲裁设置决定是否执行。

## 执行模式与自动批准列表

在智能体编辑器的“工具调用”面板中选择执行模式：

- **自动模式**：自动批准列表中的工具或方法可直接执行，其余请求进入审批流程。
- **手动模式**：所有工具调用都进入审批流程，适合需要逐项确认的场景。

工具自身的禁止策略会直接拦截调用；强制审批策略优先于自动批准列表。

## JEV 决策仲裁

在“设置 → LLM 服务”的“决策渠道”中选择具备决策能力的 JEV 模型并保存，然后在智能体的“工具调用”面板中开启“JEV 决策仲裁”。所有智能体共用全局决策渠道，仲裁开关和策略按智能体设置。

开启后，进入审批流程的请求会先接受模型审核：

- **低风险且符合用户意图**：自动批准。
- **高风险**：自动拒绝。
- **信息不足、判断不确定或渠道调用失败**：转人工审批。

仲裁使用请求所属会话活动分支上的最近一条有效用户消息作为意图参考。子智能体按自身配置参与仲裁。

可选择两种仲裁策略：

- **保守灰区**：工具要求强制审批时直接转人工，推荐日常使用。
- **激进模式**：强制审批请求也可参与仲裁，只有达到更严格的低风险标准才会自动批准。

命中静态危险特征的调用会转人工处理。风险、意图和置信度阈值可在智能体面板中调整。

## 审批交互

审核期间，工具消息显示“等待 AI 审核”；需要人工处理时，聊天界面底部显示审批栏：

- **参数预览**：点击工具名称查看调用参数。
- **单条批准**：执行该次调用。
- **拒绝**：向模型反馈该操作已被拒绝，供其调整后续步骤。
- **全部批准**：一次处理当前待批准的多个请求。

经过模型仲裁的请求会展示裁决建议与原因。后台任务等待人工处理时，也可从任务中心进入对应审批操作。

## 工具与方法设置

智能体配置支持以下控制：

- **工具开关**：控制整个工具是否可用。
- **方法开关**：按方法控制，例如允许读取文件、关闭写入文件。
- **自动批准勾选**：为常用且安全的查询操作设置自动批准。
