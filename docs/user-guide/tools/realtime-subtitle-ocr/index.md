# 字幕 OCR：本地视频离线识别

实时字幕 OCR 现在支持两种模式：

- **屏幕实时 OCR**：使用独立监控框持续识别屏幕上的字幕。
- **本地视频 OCR**：选择已经下载到本机的视频，按固定间隔抽帧并生成带原始视频时间轴的 SRT 字幕。

## 使用本地视频 OCR

1. 在工具顶部切换到 **本地视频 OCR**。此时会进入独立的编辑器式工作台。
2. 将视频拖入选择区域，或点击 **选择视频**。
3. 在监视器中拖动字幕区域（ROI）：支持 8 向手柄缩放、拖拽移动，也可在右侧 **识别设置 → 识别区域（精确）** 用像素或百分比精确设置。打开 **锁定比例** 后角点缩放会保持当前宽高比。
4. 监视器支持剪辑软件式交互：滚轮缩放、拖拽平移、适配、缩放 ±、1:1、逐帧、倍速与全屏。
5. 在右侧 **识别设置** 中选择引擎、抽帧间隔、去重灵敏度和图像滤镜。
6. 在底部时间轴上拖动绿色手柄设置开始 / 结束时间；默认识别整段视频。
7. 点击 **开始识别**，等待抽帧和 OCR 完成。识别过程中字幕块会实时出现在轨道上。
8. 在时间轴上点击 / 拖动字幕块进行选中、平移、修剪；双击进入字幕编辑；右键可 **编辑 / 在播放头拆分 / 与下一条合并 / 删除**。
9. 监视器聚焦时可用快捷键：空格播放暂停、`←/→` 逐帧、`Shift+←/→` ±1 秒、`Home/End` 首尾、`I/O` 设置识别区间起止、`F` 适配、`+/-` 缩放、`H` 手型平移。
10. 点击 **字幕列表** 打开表格式次级列表，与轨道选中、定位联动。
11. 点击 **导出 SRT** 导出标准字幕文件。

## 区域截图 · 滤镜预览（屏幕 / 视频通用）

调滤镜时可以先抓取识别区域的当前画面，实时对照滤镜效果，并用单帧直接验证 OCR：

- **视频模式**：在监视器中定位到某一帧后，点击预览面板的 **截图预览**，会按当前 ROI 抓取该帧；调整滤镜参数会自动刷新。
- **屏幕模式**：先打开并定位监控框，点击工具栏的 **区域滤镜预览**，再点击 **截图预览** 抓取监控框当前画面。
- 点击 **试识别** 使用当前引擎对处理后的区域图执行一次 OCR，便于快速确认滤镜和区域是否合适。

## 支持格式

常见格式均可尝试，包括：`.mp4`、`.mkv`、`.webm`、`.avi`、`.mov`、`.flv` 和 `.m4v`。实际解码能力由当前配置的 FFmpeg 决定。

## 时间轴和取消

- SRT 时间戳使用视频原始播放时间，可以直接配合原视频使用。
- 相邻帧中的相同或高度相似字幕会自动合并。
- 识别过程中会显示抽帧数量、OCR 完成数量和当前视频时间。
- 点击 **取消识别** 会终止 FFmpeg 和当前 OCR，已完成的字幕会保留。
- 视频抽取帧只存放在任务临时目录中，任务结束或取消后自动清理；时间轴中的缩略图会保留到当前工具会话结束。

## 注意事项

- 需要先在应用环境设置中配置可用的 FFmpeg；ffprobe 用于详细媒体信息时也应与 FFmpeg 配套。
- 字幕区域越准确，OCR 速度和识别准确率通常越好。
- 双语字幕、上下双行字幕可以选择覆盖两行的区域；复杂布局可尝试 VLM 引擎。
