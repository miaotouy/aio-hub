# 网页蒸馏室

网页蒸馏室用于搜索网页、提取正文和整理站点规则。可以直接输入网址，也可以搜索后选择来源，再将正文复制、下载或发送到聊天。

## 选择提取方式

蒸馏工作台提供四种抓取引擎；需要手动选择页面区域时，切换到「交互配方」。

| 方式               | 适合的页面或任务                               | 使用前准备                                              |
| ------------------ | ---------------------------------------------- | ------------------------------------------------------- |
| **快速模式**       | 静态文章、博客、文档，直接获取 HTML 并提取正文 | 可按站点选择身份卡片和配方                              |
| **智能模式**       | 需要 JavaScript 渲染、等待加载的动态页面       | 使用本机浏览器环境，按需要配置身份和配方                |
| **Jina Reader**    | 交给云端服务提取正文                           | 在偏好设置中配置 Jina；可留空密钥使用服务提供的匿名额度 |
| **DeepSeek Fetch** | 通过已配置的 DeepSeek 渠道提取 Markdown 正文   | 在偏好设置中选择已启用的 DeepSeek 渠道                  |
| **交互配方**       | 手动选择正文区域、排除元素、编排页面动作       | 加载页面后配置规则并保存配方                            |

快速模式、智能模式和 Jina Reader 支持 Markdown、纯文本、HTML、JSON；DeepSeek Fetch 输出 Markdown。切换引擎时，输出格式会按引擎能力选择。

Jina Reader 和 DeepSeek Fetch 由云端服务处理目标网址。站点身份卡片用于支持身份的本地提取模式；涉及登录内容时，先选择合适的本地方式。

## 第一次提取正文

1. 从主页打开「网页蒸馏室」，进入「蒸馏工作台」。
2. 在顶部地址栏输入目标网页 URL，选择提取引擎。
3. 按回车或点击抓取按钮，等待返回结果。
4. 在结果区切换正文预览和内容源码；有 HTML 快照时，还可以查看页面源码。
5. 使用「复制内容」「下载文件」或「发送到聊天」继续处理资料。

右侧信息区显示引擎、字数、输出格式和匹配配方等信息。本地提取结果会显示质量评分；云端结果主要通过正文内容判断提取效果。

如果快速模式得到的内容很少，先确认目标页面是否依赖动态加载，再尝试智能模式或云端引擎。正文混入导航和评论时，可以编辑交互配方。

## 搜索网页

### 配置渠道

1. 在 [AI 服务配置](../settings/llm-service.md) 中添加并启用 DeepSeek 渠道。
2. 回到网页蒸馏室的「偏好设置」。
3. 在「DeepSeek 搜索与抓取」中选择该渠道。

搜索与抓取会复用所选渠道的连接和网络设置。界面会提示按调用次数计费，具体费用以所选服务为准。

### 搜索与阅读

1. 打开「网页搜索」标签页，输入搜索词并设置结果数量。
2. 需要结果直接附带正文时，勾选「附带正文」。
3. 点击「搜索」，在左侧选择来源。
4. 在右侧阅读摘要，按需要打开原网页或点击「提取正文」。

结果已经包含正文时，「查看正文」会直接复用已有内容；只有摘要时，「提取正文」会通过 DeepSeek Fetch 请求正文，并将结果送入蒸馏工作台。

搜索框支持输入站点、语言和日期等限定条件，例如：

- 在特定站点搜索：`site:example.com 关键词`
- 按语言搜索：`lang:zh 关键词`
- 限定起始日期：`after:2026-10-01 关键词`

## 处理本地 HTML

通过工具栏选择文件，或将本地 HTML 文件拖入工作台，可以提取离线保存网页的正文。地址栏也支持本地绝对路径和 file:// 路径。

本地 HTML 会经过正文清洗与格式转换。网页中需要在线执行脚本才能生成的内容，建议回到原网址使用智能模式处理。

## 站点配方与交互提取

配方保存一个站点的正文规则、排除规则、元数据规则和页面动作。重复处理同类页面时，可以自动匹配已有配方。

### 编辑流程

1. 在「交互配方」中加载目标页面。
2. 使用「拾取」选中页面元素，加入包含或排除规则。
3. 在「提取规则」中整理要保留的正文和要移除的区域。
4. 页面需要点击、滚动或等待时，在「动作序列」中配置对应动作。
5. 查看「实时预览」，调整规则后保存配方。

| 动作           | 常见用途                     |
| -------------- | ---------------------------- |
| 点击           | 展开正文或切换内容           |
| 滚动           | 触发延迟加载                 |
| 等待时间或元素 | 等待目标内容出现             |
| 等待页面空闲   | 等待页面请求和渲染趋于稳定   |
| 移除元素       | 清理遮挡、提示条或无关区域   |
| 输入、悬停     | 完成页面展示正文前需要的操作 |

在「站点配方」中可以搜索、编辑、启用或禁用配方。用户配方可以删除，内置配方可以通过禁用停止使用。具体站点覆盖情况以应用内配方列表为准。

规则明确的页面可使用配方控制提取区域。提取后建议检查表格、代码块、脚注和引用链接，确认资料完整。

## 身份与 API 嗅探

### 身份卡片

在「身份卡片」中管理站点 Cookie。快速模式和智能模式可以根据当前网址匹配身份，工具栏提供身份切换入口。需要登录的页面应先确认身份有效，再重新抓取。

### API 嗅探

在智能模式和交互配方中加载页面时，可以结合「API 嗅探」查看页面发出的接口请求，包括请求方法、URL 和内容类型。需要进一步调试时，将目标接口交给 [API 测试工具](./api-tester.md)。

## 偏好设置

「偏好设置」集中配置默认抓取引擎、输出格式、Jina Reader 和 DeepSeek 渠道等选项。输出格式的实际选择受当前引擎能力限制。

纯净模式可以去除结果中的超链接，适合只需要正文的资料整理任务。需要保留引用来源时，使用带链接的输出，并核对来源 URL。

## 常见问题

### 抓取为空或正文缺失怎么办？

确认网页可正常访问。静态提取不足时尝试智能模式；登录页面检查身份卡片；正文区域特殊时使用交互配方选择内容。云端引擎失败时，核对对应渠道、密钥和网络设置。

### 为什么某些结果没有原始 HTML 快照或质量评分？

这些信息来自本地 HTML 处理过程。云端引擎直接返回正文，结果区会根据可用信息展示操作。查看页面结构时使用快速模式或智能模式。

### DeepSeek 搜索或抓取提示请求过于频繁怎么办？

稍后重试，减少同时发起的请求。确认所选 DeepSeek 渠道仍处于启用状态，并检查渠道的连接配置。

### 如何让 AI 使用提取结果？

在结果区点击「发送到聊天」，将正文和来源信息交给聊天工作区。希望智能体自行搜索或抓取时，在 [工具调用设置](./llm-chat/tool-calling/index.md) 中启用相应服务，并按需要配置审批策略。
