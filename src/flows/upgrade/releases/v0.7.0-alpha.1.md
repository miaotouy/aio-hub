# AIO Hub 0.7.0 Alpha 1

这个预发布版本开始引入统一的 **Guided Flow 分步引导基础设施**，用于承载版本升级说明、首次设置、模块引导以及后续需要用户确认的数据迁移。

## 本阶段变化

- 增加统一的分步流程容器、步骤导航和状态恢复能力；
- 增加版本生命周期记录和本地版本说明入口；
- 将“检查线上更新”和“查看已安装版本说明”拆分为两个独立动作；
- 接入旧知识库数据的只读检测、迁移预览、明确确认、执行校验和独立清理流程。

## 使用提示

- 关闭升级说明会保留当前步骤，下次启动可以继续；
- 在“设置 → 关于”中可以随时重新查看当前版本说明；
- 线上版本检查、下载和安装仍由原有应用更新器负责。

> 当前为 Alpha 预发布版本。如果遇到问题，请保留日志并通过项目仓库反馈。
