# AIO Hub 0.7.0 Alpha 1

本次预览版将思绪记忆与知识文档分开管理，新增旧数据迁移引导，以及主页最近使用和快捷入口。

## 知识资料与思绪检索

- **思绪与知识文档**：原知识库分为「思绪（Recall）」和「知识文档（Knowledge）」，分别管理记忆条目与来源文档，支持标签和检索过滤。
- **检索配置**：可以结合语义、标签和条目关联查找内容，并查看评分与运行详情。
- **智能体检索**：智能体可以通过获授权的工具查询资料。
- **备份转换**：支持将旧版思绪备份转为知识文档，转换为单向操作，请保留原始备份。

## 升级引导

- **旧数据迁移**：检测到旧数据后先展示预览，待确认后执行并检查结果，清理旧目录需要单独确认。
- **进度恢复**：关闭引导后保留进度，下次启动可继续。
- **版本说明入口**：可以在关于页与通知中心打开本地版本说明。
- **通知历史**：通知中心支持分页加载更多历史通知。

## 模型与工具调用

- **执行协议探测**：可以探测模型支持的调用协议，并保存结果供后续配置参考。
- **原生工具调用**：改善不同渠道下的工具调用兼容性。
- **人工审批等待**：审批请求默认持续等待，也可以设置超时，方便留出手动判断的时间。
- **会话保存修复**：修复会话保存、恢复和删除时的数据一致性问题。
- **Azure 连接**：修复渠道连接适配问题。
- **API Key 状态**：各渠道独立记录凭据故障状态，避免互相影响。
- **模型分组**：优先使用自定义规则，方便按自己的方式整理模型。

## 主页与其他工具

- **主页快捷入口**：可以查看最近使用的工具，固定入口并拖动排序。
- **画板**：新增星形工具和形状绘制快捷键。
- **聊天样式**：可以调整消息背景的模糊程度。
- **主页显示修复**：修复搜索框宽度、滚动条抖动和卡片阴影裁切问题。
- **目录搜索**：限制搜索资源占用，并完善取消操作。
- **文件访问权限**：加强本地文件访问和传输路径检查。

## Android 聊天

- **会话保存**：增加本地会话存储。
- **附件管理**：支持管理聊天附件及其传输。
- **消息操作**：支持停止生成、回复引用和跳转到被引用的消息。
- **富文本展示**：可以显示 Mermaid 图表、KaTeX 公式、思考块和媒体内容。
- **提示词上下文**：支持宏变量与关键词世界书，为对话补充预设内容。

> 这是 Alpha 预览版。遇到问题时，可保留日志并通过项目仓库反馈。
