# AIO Hub 0.7.0 Alpha 1

本阶段从 0.6.6 跨入 0.7.0 开发线，主线是把知识体系与升级引导产品化，同时重构主页门户与 LLM 执行链路。

## 知识库体系重构

- **思绪与知识文档双域分离**：原知识库拆分为「思绪（Recall）」与「知识文档（Knowledge）」两个独立领域，统一资料库体系；
- **检索管线落地**：语义向量、标签向量与关联联想多候选召回，融合评分，支持检索预检与显式降级，并提供可观测诊断；
- **资料管理增强**：导入导出与备份格式重构，旧版思绪备份可逆转换为 Knowledge 文档，标签管理与检索过滤，授权原子检索与目录宏；
- **首次启动迁移**：旧版 Recall 数据支持只读检测、迁移预览、明确确认、执行校验与独立清理的确认式迁移流程。

## 统一升级引导

- 引入通用 **Guided Flow** 分步引导容器，支持步骤导航、关闭后保留进度、下次启动恢复；
- 新增版本生命周期记录与本地版本说明入口（关于页 / 通知中心），线上更新与本地说明拆分为独立动作；
- 通知中心支持分页加载更多，并向持久化通知投递版本说明。

## LLM 与工具调用

- 模型执行路由：新增路由探测并持久化探测结果，为后续手工分配与自动路由提供基础；
- 原生工具调用适配修补与诊断，渠道可声明工具处理方式；
- 工具审批默认无限等待并支持可配置超时，完善审批超时与生命周期清理；
- 会话持久化原子化，修复会话恢复与删除一致性；Azure 渠道运行时适配；Key 熔断按渠道隔离并统一健康策略；
- 模型分组优先级调整，用户配置规则优先于渠道来源分类。

## 主页与交互

- 主页重构为门户布局：最近使用、快捷入口矩形卡片槽，支持拖拽排序与固定管理；
- 搜索框宽度限制、内容区滚动条抖动、卡片阴影裁切等 UI 问题修复；
- 画板新增星形工具与形状绘制快捷键；聊天支持消息背景模糊系数。

## 安全与边界

- 目录搜索增加资源安全限制与完整取消生命周期（含 VCP 分布式取消）与 Agent 同行结果合并；
- 数据过滤器隔离 Agent 自定义脚本能力；文件操作与内置传输路径沙箱边界加固；
- 供应链依赖安全检查；插件引入 Sidecar Plugin API v3 与进程代际隔离、结构化诊断。

## 移动端（Android）

- Chat 产品化推进：SQLite 会话存储、附件资产系统与托管传输、富文本渲染器（Mermaid / KaTeX / 思考块 / 受管媒体）、宏变量与关键词世界书、停止生成、消息回复引用与导航等。

## 工程与测试

- 引入 WebdriverIO Tauri E2E 框架、Windows 原生对话框 UI Automation 与 Android AVD 回归；
- 统一桌面与移动端构建脚本与版本管理，新增构建版行为测试脚本。
