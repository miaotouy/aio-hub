# AIO Hub 0.7.0 Alpha 2

本次完善模型执行协议设置，聊天新增「等待中」状态，并修复自定义 CSS 启动时未生效的问题。

## 模型与渠道

- **手动选择执行协议**：可以指定模型使用的调用协议，也可应用探测结果。
- **聚合渠道**：支持集中管理多个上游，并设置渠道默认协议。
- **DeepSeek V4 适配**：按正式版调整思考控制和话题命名。

## LLM 对话与提示词

- **消息等待状态**：可以区分排队、等待与生成，修复等待转生成时三点指示器偶尔消失的问题。
- **应用版本宏**：新增 `appVersion`，可在提示词中引用当前应用版本。

## 修复

- **WebCanvas 审批**：修复工具审批状态同步异常。
- **WebCanvas 文件访问**：修复文件访问权限检查问题。
- **VCP 工具调用**：修复相邻请求被合并、调用结果互相干扰的问题。
- **自定义 CSS**：修复应用启动时自定义样式未生效的问题。

> 这是 Alpha 阶段记录，内容对应当时已合入的改动。遇到问题时，可保留日志并通过项目仓库反馈。
