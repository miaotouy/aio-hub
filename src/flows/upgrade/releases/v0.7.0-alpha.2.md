# AIO Hub 0.7.0 Alpha 2

> 本版本仍在施工中，以下为截至当前已合入的改动，正式发布前可能继续补充。

## 新增

- **模型执行路由**：支持手工分配执行路由，并将路由探测结果正式应用到实际执行；
- **聚合渠道**：新增聚合渠道类型与渠道级默认协议路由，方便统一管理多个上游；
- **DeepSeek V4 对齐**：对齐正式版的思考控制与话题命名行为；
- **聊天状态细化**：消息状态新增「等待中」阶段，排队与等待过程更直观；
- **模板宏扩展**：新增 `appVersion` 宏，可在提示词中补充应用版本信息。

## 修复

- 修复等待中切换到生成中时三点流式指示器偶发消失；
- WebCanvas：修复审批同步与文件安全边界，恢复审批前内存预算；
- 防止 VCP 请求块合并，避免工具调用结果串扰；
- 恢复应用初始化时自定义 CSS 未生效的问题。

## 工程

- 固定 Bun 版本，调整 CI 依赖安装选项；
- 统一桌面与 Android E2E 命令入口。

> 当前为 Alpha 预发布版本。如果遇到问题，请保留日志并通过项目仓库反馈。
