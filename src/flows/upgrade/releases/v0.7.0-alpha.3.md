# AIO Hub 0.7.0 Alpha 3

本版本继续打磨模型元数据体系与媒体生成链路，并补强日志与设置持久化的稳定性。

## 模型与 LLM 服务

- **模型元数据 v3**：建立新的规则核心与分层存储，物化模型元数据并收紧运行时边界，支持目录更新与模型刷新前预览；
- **嵌入模型身份配置**：新增嵌入能力检测，仅对嵌入模型展示专属的身份配置区块，并优化向量复用判断的输入体验；
- **聚合渠道图标**：聚合渠道提供商支持显式图标与更清晰的分组配置；
- **思考模型 token 预留**：新增思考模型预留 token 配置项；
- **模型元数据补充**：新增 Agnes AI 模型元数据并增强诊断日志。

## LLM 对话

- **排队系统**：优化排队系统逻辑并修复相关问题；
- **模型图标与快照**：修复模型图标显示错误，聊天消息支持历史快照；
- **Token 计算**：修复 Worker 无法接收 Vue 响应式对象的问题。

## 媒体生成与工具

- **媒体生成器**：新增多模态快捷提示词库与光标插入，重构生成输入框与工具栏布局，结果下载支持独立超时，生成过程中可编辑草稿；
- **FFmpeg 工具**：新增原始分辨率画质预设并优化预设切换体验；
- **VCP 连接器**：新增消息通知设置；
- **目录树**：`.gitignore` 规则不再读取父目录的忽略文件；
- **转写**：修复转写总开关优先级，关闭时短路所有转写逻辑；
- **监控**：支持长按或 Ctrl 点击独选消息类型，修复虚拟列表筛选后的高度缓存异常。

## 界面与稳定性

- 优化首页按钮与卡片圆角阴影、模型列表与 Profile 侧边栏样式，修复 sticky 组件顶部偏移导致的滚动抖动；
- 修复工具可见性设置无法持久化、侧边栏残留过期打开工具记录；
- 提升前端日志持久化可靠性，修复后端日志跨日与滚动丢失。

## 工程

- 避免插件脚本与无效动态导入进入构建；
- 发布说明资源缺失检查调整为非阻断警告。

> 当前为 Alpha 预发布版本。如果遇到问题，请保留日志并通过项目仓库反馈。
