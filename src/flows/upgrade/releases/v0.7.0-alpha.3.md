# AIO Hub 0.7.0 Alpha 3

媒体生成新增快捷提示词库，生成时可继续编辑草稿。模型刷新支持预览变化，话题命名增加思考模型的推理额度设置。

## 媒体生成

- **快捷提示词库**：可以保存常用多模态提示词，并按光标位置插入，减少重复输入。
- **生成中编辑草稿**：调整输入框和工具栏布局，任务进行时可以继续准备下一条输入。
- **结果下载超时**：可以单独设置下载等待时间，适应较大的媒体文件。

## 模型与渠道

- **刷新预览**：更新模型目录或刷新模型前，可以核对即将变化的能力与配置。
- **嵌入模型向量复用**：更换同款嵌入模型的服务渠道时，可在专属设置中核对模型身份与向量配置，判断能否沿用已有向量。
- **模型能力资料**：补充 Agnes AI 模型资料。
- **聚合渠道展示**：可以设置提供商图标与分组，便于在列表中识别渠道。

## LLM 对话

- **话题命名推理额度**：使用思考模型生成会话标题时，可以额外预留推理 Token，减少推理消耗挤占标题输出额度的情况。
- **消息排队**：修复排队相关问题。
- **历史快照**：聊天消息支持保留历史快照。
- **模型图标**：修复消息中的模型图标显示错误。
- **Token 统计**：修复部分数据导致用量计算失败的问题。

## 其他工具

- **FFmpeg**：新增原始分辨率预设，可直接选择保持原始画面尺寸。
- **VCP 连接器**：增加消息通知设置。
- **目录树**：只使用当前目录范围内的忽略规则，避免父目录的 `.gitignore` 影响当前结果。
- **转写总开关**：修复关闭后部分转写逻辑仍然运行的问题。
- **监控筛选**：长按或 Ctrl 点击可以只看一种消息类型，修复筛选后列表高度异常。

## 界面与设置

- **界面样式**：调整首页、模型列表和 Profile 侧边栏的样式。
- **吸顶组件**：修复顶部偏移引起的滚动抖动。
- **工具可见性**：修复设置后未保存的问题。
- **侧边栏记录**：清理过期的已打开工具记录。
- **日志保存**：修复跨日和滚动时日志丢失的问题。

> 这是 Alpha 预览版。遇到问题时，可保留日志并通过项目仓库反馈。
