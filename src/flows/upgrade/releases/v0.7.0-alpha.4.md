# AIO Hub 0.7.0 Alpha 4

本版本以 Git Committer、色彩整理与实时字幕 OCR 三条工具链的大规模重构为主线，并完成 FFmpeg 工作台的阶段性改造。

## Git Committer

- **提交与差异浏览**：新增提交详情悬浮卡片与远端跳转，支持查看提交的文件变更与差异；
- **差异导航**：新增差异导航工具条与折叠未更改区域，打开 Diff 时自动定位到首处改动；
- **更改总览**：新增更改总览标签页与放弃更改功能；
- **AI 提交**：新增仓库级 AI 提示词编辑标签页与每仓库专属 System Prompt，引入提交语言设置与结构化 Prompt 模板，支持中止 AI 生成提交信息并隔离多仓库状态；
- **仓库管理**：仓库图标支持自定义颜色与配色色盘，修复仓库列表拖拽排序与侧边栏拖拽手柄双击复位等问题；
- **稳定性**：暂存文件改用系统 `git add`，修复切换仓库时设置面板未关闭、Monaco Diff 编辑器模型销毁顺序错误与 ECharts 初始化时机问题。

## 色彩整理工具

- **批量分析**：批量图片颜色分析迁移至 Rust 后端并行处理，改为异步流式进度上报，并调整并行线程数；
- **结果浏览**：批量结果支持缩略图预览，修复虚拟列表滚动位置跳变，工具栏支持拖拽筛选与反选；
- **归档整理**：支持通过路径输入或拖拽选择目录进行批量扫描，归档改为对话框并支持自定义分类结构与自动选择过滤结果；
- **分类与阈值**：色系分类迁移到圆盘点位最近邻，亮度阈值组件支持 1-4 档动态调节、拖拽微调与重置默认。

## 实时字幕 OCR

- **工作台重构**：屏幕实时 OCR 模式改为编辑器式工作台，支持行内编辑、区域预览与自适应布局，并按壳子/工作台拆分并隔离双模式字幕 store；
- **本地视频离线识别**：支持本地视频离线 OCR 识别；
- **字幕编辑器**：重做字幕编辑器并增强视频监视器交互；
- **图像滤镜**：新增 OCR 图像滤镜，支持原图/滤镜对比预览；
- **稳定性**：修复多实例卸载时提前销毁共享状态、会话竞态与滤镜性能问题。

## FFmpeg 工作台

- 统一执行计划、终端复制与编码器质量策略；
- 统一自动命名、输出安全与输出容器；
- 单文件卡片状态与结构化进度反馈；
- 自定义参数积木式作用域编辑；
- 时间片段裁剪与关键帧吸附；
- 修复任务生命周期与提交防重，命令预览输出路径与实际执行保持一致。

## 其他工具与体验

- **翻译器**：支持展示和干预模型思考过程；
- **PDF 阅读器**：新增适应高度功能，支持宽高方向切换；
- **符号搬家**：引入预检与事务式搬家机制；
- **OCR**：新增引擎就绪检查和预热机制；
- **模型探测**：区分本地代理错误与上游服务端错误；
- **模型元数据**：内置目录改为随版本自动更新，补充 DeepSeek V4.1 Flash 与 GLM-5.2/5.3 元数据并修复能力匹配问题；
- **LLM 对话**：兼容拒绝空文本的 API（纯图片消息自动补充占位文本），修复会话切换竞态与停止排队消息状态，附件添加支持静默模式；
- **首页**：新增 Doodle 彩蛋与标志、顶部浮动消息组件，工具分类栏布局与卡片样式支持用户自定义；
- **主题**：壁纸提取主题色增加语义色相避碰；
- **其他**：模型列表按名称与版本号自然排序，组件测试器支持自定义消息内容。
