# AIO Hub 0.7.0 Alpha 4

Git Committer 增加差异导航与仓库专属 AI 提交设置，色彩整理支持目录扫描和自定义归档，字幕 OCR 新增本地视频离线识别。

## Git Committer

- **提交详情**：可以查看提交涉及的文件变化，并跳转远端。
- **差异导航**：支持在改动之间跳转、折叠未修改区域，打开时定位到首处改动。
- **更改总览**：可以集中查看工作区变化，并放弃更改。
- **仓库专属 AI 设置**：各仓库可设置提交提示词与语言，生成过程中支持中止。
- **仓库标识颜色**：可以为各仓库设置不同颜色，方便在列表中区分。
- **仓库管理修复**：修复拖拽排序、切换仓库后面板残留和差异视图异常。

## 色彩整理

- **目录批量扫描**：可以输入路径或拖入目录，分析过程中显示进度。
- **缩略图筛选**：可以浏览、筛选和反选结果，修复滚动位置跳变的问题。
- **自定义归档**：可以在弹窗中配置分类结构，将筛选结果归档。
- **亮度分类**：可以设置 1–4 档亮度分类，支持拖拽微调和恢复默认。

## 实时字幕 OCR

- **本地视频识别**：新增离线字幕 OCR，支持行内编辑、识别区域预览和视频监视器操作。
- **屏幕识别滤镜**：可以对比原图与处理效果，辅助调整识别画面。
- **稳定性修复**：修复多实例运行和切换会话时的异常，改善滤镜性能。

## FFmpeg

- **片段裁剪**：支持按时间裁剪，并吸附关键帧。
- **参数编辑**：可以按作用范围组织自定义参数，方便检查参数应用在哪个输入或输出上。
- **处理进度**：单个文件可以查看状态与进度。
- **输出文件保护**：调整自动命名、格式和覆盖检查，命令预览路径与实际执行保持一致。
- **重复任务修复**：修复重复提交任务的问题。

## 其他工具

- **翻译器**：支持查看和干预模型思考过程。
- **PDF 阅读器**：支持适应高度，并可切换按宽度或高度适应页面。
- **符号链接搬家工具**：搬家前先检查，出错时尝试回滚，降低移动中断后的恢复难度。
- **OCR 引擎**：启动识别前检查引擎是否就绪，并进行预热。

## 模型、聊天与界面

- **模型连接排查**：区分本地代理和上游错误，帮助判断连接失败的位置。
- **模型能力目录**：随应用版本更新内置资料，补充 DeepSeek V4.1 Flash 和 GLM-5.2/5.3。
- **模型排序**：按名称和版本号自然排序，便于查找不同版本。
- **聊天兼容**：改善纯图片消息的 API 兼容性，修复切换会话和停止排队消息时的状态异常。
- **主页自定义**：可以调整工具分类栏布局与卡片样式。
- **主页 Doodle**：增加彩蛋与标志展示。
- **顶部提示消息**：增加顶部浮动消息展示。
- **主题配色**：调整壁纸提取配色，减少主题色与状态提示色混淆。

> 这是 Alpha 预览版。遇到问题时，可保留日志并通过项目仓库反馈。
