# AIO Hub 0.7.0 Alpha 5

新增子智能体后台任务中心，可查看进度、追加指导和取消任务。Git Committer 支持媒体差异预览，Token 计算器支持压缩包导入分词器。

## 子智能体与后台任务

- **任务中心**：可以查看状态与活动记录、追加指导或取消任务，主窗口和聊天区均有入口，主会话显示关联派遣卡片。
- **伴生分栏**：可以并排查看后台任务进展。
- **标题栏任务状态**：可以查看后台任务的活动情况。
- **消息发送者**：消息和导出记录会标明调度方、子智能体与用户介入，便于区分内容来源。
- **子智能体开关**：可以在智能体管理页控制是否启用子智能体。

## Git Committer

- **媒体差异预览**：可以直接预览提交和暂存差异中的媒体文件。
- **AI 提交信息**：使用实际差异减少上下文消耗，并自动清理输出外层的代码块标记。
- **提交历史加载**：优化历史记录的加载。
- **标签栏滚动**：可以用滚轮横向浏览标签栏，并定位到当前标签，修复标签溢出问题。

## Token 计算器

- **压缩包导入**：可以从 ZIP、TAR、TAR.GZ 导入 Hugging Face 分词器。
- **图片用量估算**：支持计算 DeepSeek V4.1 视觉输入的 Token 用量。

## LLM 对话与模型设置

- **新会话草稿**：发送首条消息前以草稿形式保留，修复选择会话时的保存问题。
- **首次启动**：改善默认智能体创建与模型选择流程。
- **决策模型渠道**：接入 TypeSafe AI System One。
- **视频能力识别**：补充 GLM-5.3-Flash 的视频能力信息。
- **模型选择器**：滚动时保持渠道标题可见，方便辨认模型所属渠道。
- **智能体导入预览**：可以查看头像和打包资产，再决定是否导入。
- **聊天布局**：调整气泡操作栏、状态标记和用量信息。
- **凭据存储**：API Key 改为与常规配置分开存放。

## 修复

- **VCP 解析**：修复工具内容中的协议结束标记被误识别的问题。
- **智能体迁移**：修复旧版字段缺失导致无法保存的问题。
- **代码编辑器**：修复部分中文提示错位的问题。
- **LLM 配置导入**：修复导入 JSON 配置时出现格式误报的问题。
- **版本更新通知**：优先展示最新版本。
- **资源路径**：修复空路径的处理问题。

> 这是 Alpha 预览版。遇到问题时，可保留日志并通过项目仓库反馈。
