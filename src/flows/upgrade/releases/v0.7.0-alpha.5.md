# AIO Hub 0.7.0 Alpha 5

本版本聚焦于子智能体（Sub-Agent）后台调度系统与可观测性基础设施落地、LLM 凭据安全隔离，以及 Git Committer 与 Token 计算器的功能增强。

## 子智能体与后台任务

- **后台任务调度与任务中心**：新增后台任务系统，调度 Agent 可发起非阻塞异步任务（`ask({ mode: "background" })`），支持查询状态、活动记录、追加指导与取消；
- **可观测性与任务透视**：主窗口与聊天区集成任务中心入口及标题栏活动胶囊，主会话工具消息关联后台任务并提供派遣卡片；新增只读伴生分栏视图，支持结构性让位与双模透视；
- **多源身份呈现**：在消息节点和导出记录中呈现真实发送者（调度方、子 Agent、用户介入），支持从任务中心追加用户指导；
- **Agent 配置扩展**：智能体管理新增 `subAgentConfig.enabled` 开关，支持独立子会话调用与执行所有权收紧。

## 安全与凭据

- **LLM 凭据隔离**：将 LLM 凭据从常规配置中分离到独立的混淆存储，并增加哈希索引。

## LLM 对话与模型管理

- **虚拟新会话草稿**：新增虚拟新会话，首条消息发送前不持久化会话；修复选定前物化会话的持久化问题；
- **首次启动流程**：改进首次启动时默认智能体的创建与模型选择流程；
- **决策渠道**：接入 TypeSafe AI System One 决策渠道；
- **模型与渠道**：模型选择器滚动时固定展示渠道头部；模型元数据标记 GLM-5.3-Flash 支持视频能力；
- **智能体导入**：智能体导入支持预览头像及打包资产；
- **气泡消息与布局**：优化气泡消息操作栏位置与状态徽标，紧凑化消息字符与 Token 用量元数据。

## Git Committer

- 支持提交与暂存差异中的媒体文件预览；
- 新增 HEAD 哈希追踪以优化提交历史加载；
- 采用 unified diff 替代完整文件快照生成提交信息，大幅减少上下文消耗；
- 支持剥离提交消息外层的代码围栏包裹；
- Tab 标签栏交互优化，支持鼠标滚轮横向滚动并自动定位激活标签，修复标签页布局溢出。

## Token 计算器

- 支持从 ZIP、TAR 与 TAR.GZ 压缩包导入 Hugging Face tokenizer；
- 接入 DeepSeek 官方 14px patch 与 3 倍降采样算法，支持 DeepSeek V4.1 视觉输入 token 计算。

## 修复与工程

- 修复 `convertToAssetProtocol` 对空路径参数的处理；
- 修复 VCP 解析器误识别 `Content` 字段内协议结束符的问题；
- 补齐旧版 Agent 迁移时缺失的核心字段，避免迁移保存被拦截；
- 修复 Monaco 0.55.1 中文语言包消息数组索引错位；
- 修复 LLM 配置导入时对 JSON 文件的 TOML 解析报错；
- 版本更新通知按最新版本优先展示；
- 新增中文 Knowledge 语料 E2E 测试及准备脚本；
- 引入玻璃材质性能对比探针与受控采集通道，并在验证后正式收敛结论。
