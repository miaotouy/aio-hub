# AIO Hub 0.7.0 Alpha 6

本版本重点推进了 Git Committer 深度能力完善、内置子智能体释出与调度治理、智能体/Skill 体验升级，以及大量用户反馈问题的高密度修复。

## Git Committer

- **分支泳道图**：新增 Git 分支泳道可视化组件，直观呈现分支流转与合并拓扑；
- **文件与内容搜索**：新增工作区文件与代码内容实时搜索功能；
- **交互与右键菜单**：补全完整右键菜单体系，区分未跟踪文件的「删除」与「放弃」操作，支持查看文件当前内容；
- **历史记录与时间树**：重构提交历史时间树节点与连线视觉样式，新增打开仓库目录按钮，修复历史刷新时列表偶发消失的问题；
- **索引优化**：`git-analyzer` 将 `commitRange` 索引体系规范化为 1-based。

## 子智能体与 Skill

- **内置子智能体释出**：实现内置开箱即用子智能体的按需释出机制与调度层配额/并发管控；
- **Skill 概览与编辑**：重构 Skill 概览页为双栏布局并消除滚动冲突，合并概览与指令标签展示；
- **JEV 协议识别**：支持自然语言工具调用的 JEV 语法识别；
- **文件操作工具扩展**：`aio-file-operator` 扩展支持复制、移动、元数据读取与搜索动作，并对长错误回显做截断保护。

## LLM 对话与服务

- **斜杠命令**：输入框支持斜杠命令（`/`）智能联想补全与快捷执行；
- **批量导入模型**：LLM 服务新增批量添加模型功能，支持多格式 ID 解析与添加状态筛选，支持从获取模型窗口取消已勾选模型；
- **Token 与缓存感知**：消息 Token 用量显示模型缓存命中量，发送前图片 Token 预估计入压缩缩放；
- **网络与重试韧性**：新增自动重试 HTTP 状态码白名单，Web Distillery 接入应用统一代理并启用系统代理支持；
- **气泡消息与布局优化**：重做气泡模式操作栏为悬浮式并消除常驻占位，修复卡片与气泡模式下消息底边裁剪及编辑框失焦问题；
- **虚拟会话稳定性**：新会话入口统一走草稿会话并修复持久化丢失问题。

## 窗口自动化 (Window Automator)

- **中心坐标系**：实现坐标系重构为中心坐标系，简化多分辨率自适应定位；
- **键鼠模拟**：新增前台/后台双模式点击与键盘输入模拟。

## 媒体生成与转写

- **媒体任务控制**：图像生成任务的重新生成按钮改为常驻展示，优化取消状态图标并支持查看完整错误详情；
- **任务终态守卫**：针对 Agnes 渠道引入全局 watchdog 与超时终态保护，避免卡在入库状态；
- **转写与异常检测**：转写新增模型拒绝与异常检测结果警告，优化复读检查阈值与占位行过滤。

## 系统与安装体验

- **自定义数据目录**：Windows 安装器支持自定义用户数据存储路径；
- **覆盖安装提示**：重新安装时显示当前已安装版本与待安装版本号；
- **安装器视觉**：更新 NSIS 安装程序高分屏图标资源与页面样式；
- **版本更新列表**：升级说明列表修复横向溢出并支持关键词检索，当前版本判定统一改为按运行时解析；
- **UI 层级**：修复顶部浮动消息可能被弹窗遮挡的问题，自动同步弹窗 z-index。
