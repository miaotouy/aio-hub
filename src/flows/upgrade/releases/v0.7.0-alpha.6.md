# AIO Hub 0.7.0 Alpha 6

Git Committer 新增分支泳道图和文件、代码搜索。聊天支持斜杠命令，Windows 安装可以指定数据目录。

## Git Committer

- **分支泳道图**：通过图形查看提交之间的分支与合并关系。
- **文件与代码搜索**：可以按文件名或内容搜索工作区。
- **工作区右键操作**：支持查看文件当前内容，区分未跟踪文件的「删除」与「放弃」。
- **仓库目录入口**：新增打开仓库目录的按钮。
- **历史列表修复**：调整节点和连线样式，修复刷新时列表偶尔消失的问题。

## 子智能体与 Skill

- **内置子智能体**：可以按需使用内置能力，并设置同时运行的任务数量。
- **Skill 双栏概览**：集中展示说明与指令，减少嵌套滚动。
- **JEV 工具调用**：支持识别自然语言调用语法。
- **本地文件工具**：支持复制、移动、元数据读取和搜索，并简化长错误信息展示。

## LLM 对话与模型

- **斜杠命令**：在输入框键入 `/`，即可联想补全并执行快捷操作。
- **批量添加模型**：支持解析多种格式的模型 ID，按添加状态筛选，并取消已勾选的模型。
- **Token 用量**：展示缓存命中量，发送前的图片估算会计入压缩和缩放结果。
- **自动重试**：可以指定允许自动重试的 HTTP 状态码，控制重试范围。
- **聊天气泡布局**：操作栏改为悬浮展示，修复消息底部裁剪和编辑框失焦的问题。
- **新会话草稿**：修复草稿保存丢失的问题。
- **网页提炼代理**：接入应用统一代理并支持系统代理。

## 媒体生成与转写

- **生成任务操作**：重新生成按钮保持可见，取消状态和完整错误详情更易查看。
- **任务状态修复**：修复 Agnes 渠道部分任务长期停留在入库状态的问题。
- **转写异常提醒**：可以识别模型拒绝或异常输出，改善复读检查和占位行过滤。

## 窗口自动化

- **中心坐标定位**：可以按相对窗口中心或自定义标定点的方向和距离设置点击，便于配置角色周围的操作。标定原点随窗口尺寸变化保持相对位置。
- **键鼠模拟模式**：新增前台、后台两种点击与键盘输入模式。

## 安装与系统界面

- **Windows 安装目录**：可以自定义用户数据的存放位置。
- **覆盖安装提示**：同时显示已安装和待安装版本，方便确认本次安装内容。
- **安装器显示**：改善高分屏下的图标与页面样式。
- **版本说明列表**：支持关键词搜索，修复横向溢出和当前版本识别的问题。
- **提示消息层级**：修复顶部提示被弹窗遮挡的问题。

> 这是 Alpha 预览版。遇到问题时，可保留日志并通过项目仓库反馈。
