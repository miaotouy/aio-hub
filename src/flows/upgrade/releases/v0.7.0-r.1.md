# AIO Hub 0.7.0-r.1

本次汇总 **0.6.6-r.2** 以来的更新。主要变化包括思绪与知识文档分开管理、子智能体后台任务、主备模型组合，以及 Git、媒体生成和字幕 OCR 的功能扩展。旧知识数据的迁移与备份事项见文末。

## 知识资料与思绪检索

- **思绪与知识文档**：原知识库分为「思绪（Recall）」和「知识文档（Knowledge）」，分别管理记忆条目和来源文档。
- **资料工作台**：支持导入文件、同步目录来源、管理标签和筛选检索结果，可查看导入任务进度。
- **聊天引用资料**：可以在聊天中明确引用文档，便于补充本次提问所需的资料。
- **智能体检索授权**：可以授权智能体通过工具查询资料，也可通过全局开关控制知识库访问。
- **思绪检索**：结合语义、标签和条目关联寻找内容，支持选择检索预设、调整检索步骤，并查看评分与运行详情。
- **跨渠道复用向量**：确认两侧为同款嵌入模型且向量配置一致后，可以手动切换服务渠道并保留已有向量，省去重新计算整库。
- **旧备份恢复与转换**：兼容旧版思绪备份，并支持将其转换为知识文档。
- **旧数据迁移**：升级时提供迁移预览、确认、执行进度与结果报告，帮助检查资料是否完整。
- **检索结果刷新**：修复删除资料后仍能搜到旧内容，以及更新数据后检索结果未刷新的问题。
- **资料库路径**：修复迁移应用数据目录后资料库路径异常的问题。

## LLM 对话

- **斜杠命令**：在输入框键入 `/` 即可搜索并执行命令，支持拼音检索和分组选择。
- **输入工具栏布局**：可以调整按钮顺序、常用操作和右侧状态显示。
- **输入面板展开**：可以展开或收起输入区，并设置重复点击按钮时的行为。
- **新会话草稿**：草稿会持久保存，刷新后可继续编辑，工具栏也增加了新建会话入口。
- **会话导入导出**：支持将单个完整会话导出为 JSON 并重新导入，保留关联附件和上下文参数。
- **上下文压缩**：可按用户回合压缩长对话，连续压缩时继承已有摘要。
- **Token 用量**：消息用量增加缓存命中信息，发送前的图片估算会计入压缩和缩放结果。
- **自动重试**：可以指定允许自动重试的 HTTP 状态码，控制哪些请求错误需要重试。
- **VCP 分段消息**：可将上游响应拆成多条消息展示，并查看思考状态与耗时，默认关闭。
- **长会话阅读**：改善滚动性能、阅读位置保持和工具调用展开布局。
- **批量会话搜索**：支持搜索会话正文，并高亮匹配内容。
- **生成中断恢复**：中断后保留已接收内容，加载会话时修正意外中断留下的生成状态。
- **会话存储修复**：修复保存、删除和恢复会话时的数据一致性问题。
- **消息重试**：修复部分父消息角色导致无法重试的问题。
- **排队消息分支**：修复排队消息与分段消息的分支冲突。

## 模型与渠道

- **主备模型组合**：新增虚拟渠道，集中配置主模型、备用模型和失败切换方式，各工具可保留自己指定的模型。
- **渠道配置导入导出**：支持应用原生格式及 New API「复制连接信息」，减少手动填写连接参数。
- **批量添加模型**：可以一次填写多个模型 ID，批量添加到渠道。
- **模型执行协议**：可以手动指定模型使用的协议，也可应用探测结果。
- **聚合渠道默认协议**：可以统一设置渠道中的默认协议，减少逐个模型配置的操作。
- **模型刷新预览**：刷新前可以查看模型能力和配置的变化，再决定是否应用。
- **参数兼容**：按模型能力处理输出预算与采样参数，减少参数不适用导致的请求失败。
- **本地音频渠道**：接入 audio.cpp。
- **语音转写接口**：支持专用的语音转写端点。
- **决策模型渠道**：增加 TypeSafe AI System One 支持。
- **OpenRouter 多媒体适配**：补充图像、视频、语音及 Decisions 协议支持。
- **模型适配更新**：更新 DeepSeek、Claude、GPT、Gemini、GLM、Agnes 与 Jev 的能力和请求适配。
- **Azure 连接**：修复渠道连接适配异常。
- **渠道配置导入**：修复导入配置时出现误报的问题。
- **API Key 状态**：修复健康检查与连接测试结果不一致的问题，全部凭据不可用时给出明确提示。

## 智能体与后台任务

- **子智能体任务中心**：可以派遣后台任务、查看进度与活动记录、追加指导或停止任务，主会话显示关联任务卡片。
- **伴生视图**：可以并排查看后台任务上下文和实时进度。
- **任务跨窗口同步**：多个窗口会同步后台任务状态，消息中标明实际发送者。
- **内置子智能体**：可按需使用内置能力，并配置任务并发与调度方式。
- **工具审批**：后台任务支持审批，可选择 JEV 决策模型或普通 LLM 辅助判断。人工审批默认持续等待，也可设置超时。
- **智能体参数页**：增加独立的模型参数与上下文设置页，便于为不同智能体配置各自的生成方式。
- **智能体描述**：卡片增加短描述和悬浮提示，支持生成描述与批量补全。
- **Skill 概览**：改为双栏展示，集中查看说明、脚本和权限。
- **智能体导入修复**：修复导入、升级恢复和覆盖更新时的名称保留问题。
- **工具权限检查**：加强文件访问、VCP 传输与脚本执行的权限检查，修改工具策略时需要确认。

## Git 工作台

- **分支泳道图**：通过图形查看提交之间的分支与合并关系。
- **仓库全景**：新增仓库概览视图。
- **工作区搜索**：可以按文件名或代码内容查找文件。
- **差异导航**：支持跳转改动、折叠未修改区域，打开后定位第一处变化。
- **提交详情**：可以查看提交涉及的文件变更，并跳转远端。
- **媒体差异预览**：提交与暂存差异中的图片、音频等媒体可以直接预览，支持预览标签页和 Alt 临时预览。
- **更改总览**：新增标签页，集中查看工作区改动。
- **仓库目录入口**：可以直接打开当前仓库所在目录。
- **工作区右键操作**：补充常用菜单，区分未跟踪文件的「删除」与「放弃」。
- **AI 提交信息**：各仓库可单独设置提示词与提交语言。生成时使用实际差异，减少上下文消耗，并支持中止。
- **仓库标识颜色**：可以为各仓库设置不同颜色，便于在列表中区分。
- **创建并推送标签**：新增统一操作弹窗，创建 Git 标签后可直接推送到远端。
- **历史记录修复**：修复历史刷新后列表消失和分支加载异常，历史统计移除 5,000 条上限。
- **仓库排序修复**：修复拖拽调整仓库顺序的问题。

## 媒体生成

- **全局任务队列**：可以集中管理并发生成任务，并切换任务列表视图。
- **生成中编辑草稿**：任务进行时可以继续准备输入内容，附件会随会话保存。
- **快捷提示词库**：常用多模态提示词可保存并按光标位置插入，减少重复输入。
- **参考图辅助优化**：提示词优化可以携带参考图，让模型结合图片调整描述。
- **视频与音乐进度**：任务可以显示上游返回的生成进度。
- **结果下载超时**：可以单独设置下载等待时间，适应较大的媒体文件。
- **任务控制修复**：改善重新生成、取消和失败详情，修复部分任务长期停留在处理中或入库中的问题。

## 转写与网页提炼

- **转写异常提醒**：遇到模型拒绝或异常输出时给出提示，减少复读、占位行和额外说明。
- **转写开关修复**：修复总开关与活跃任务筛选问题。
- **网页提取来源**：新增 Jina 云端提取、DeepSeek 搜索与网页抓取，改善正文提取和文档转换。
- **网页提炼代理**：接入应用统一代理设置。

## 视频、字幕与图像工具

- **FFmpeg 序列帧合成**：可以将图片序列合成为视频，支持拖入和刷新帧文件。
- **FFmpeg 编码选择**：简单模式可以选择 CPU 或 GPU 编码。
- **FFmpeg 分辨率预设**：可以直接选择保留原始画面尺寸。
- **FFmpeg 片段裁剪**：支持按时间裁剪，并吸附关键帧。
- **FFmpeg 参数编辑**：可以按作用范围组织自定义参数。
- **FFmpeg 处理进度**：可以查看单个文件的状态和进度。
- **FFmpeg 输出文件保护**：完善自动命名与覆盖检查，减少覆盖已有文件的风险。
- **本地视频字幕 OCR**：支持离线识别、字幕行内编辑、时间轴吸附和识别区域预览。
- **屏幕字幕 OCR**：增加图像滤镜与原图对比，改善多实例运行和截图稳定性。
- **色彩整理归档**：可以扫描目录并批量分析图片、SVG 代表色，通过缩略图筛选后按自定义分类归档。
- **色彩亮度分类**：支持设置 1–4 档亮度分类、拖拽微调和预设管理。
- **画板**：增加星形工具、形状绘制快捷键和 PNG 导出到剪贴板。
- **文档预览**：增加 WPS 与 OpenDocument 格式支持。

## 文件与自动化工具

- **本地文件操作**：增加复制、移动、重命名、元数据读取和搜索，完善规则编辑与操作审计，简化长路径报错。
- **目录搜索**：可以完整取消搜索，并限制资源占用。
- **符号链接搬家工具**：搬家前检查空间和权限，出错时尝试回滚，降低移动中断后的恢复难度。
- **数据筛选**：增加纯文本模式，可以随机删行、保留指定行数或按关键字保留内容。
- **窗口自动化定位**：可以按相对窗口中心或自定义标定点的方向和距离设置点击，便于配置角色周围的操作。标定原点随窗口尺寸变化保持相对位置。
- **窗口自动化键鼠模拟**：新增前台、后台两种点击与键盘输入模式。
- **分词器导入**：Token 计算器支持从 ZIP、TAR、TAR.GZ 导入 Hugging Face 分词器。
- **图片 Token 估算**：Token 计算器支持估算 DeepSeek V4.1 的视觉输入用量。

## 系统与界面

- **主页快捷入口**：增加最近使用工具和可拖拽的快捷入口。
- **设置导航**：改为分组两级导航，便于定位设置项。
- **Windows 安装目录**：安装时可以指定用户数据目录。
- **覆盖安装提示**：同时显示已安装版本与待安装版本。
- **历史版本说明**：支持浏览历史版本、搜索内容和识别当前版本。
- **通知中心**：支持分页加载更多通知。
- **弹层交互**：改善焦点、Escape 关闭和通知层级。
- **工具可见性**：修复设置后未保存的问题。
- **文件定位**：修复 Windows 打开文件所在目录失败的问题。
- **日志保存**：修复滚动时日志丢失的问题。
- **富文本显示修复**：改善工具调用、代码围栏和附件卡片的显示。
- **图片资源提示**：图片缺失时显示带资源信息的占位提示。
- **插件运行修复**：改善诊断、平台检查和进程重启后的状态处理。

## 升级提醒

- **备份**：从 0.6.6-r.2 升级前，建议备份重要会话、智能体和知识数据。
- **旧数据迁移**：按引导完成确认与检查，旧目录默认保留，确认资料完整后再清理回收空间。
- **备份转换**：旧版思绪备份转知识文档为单向转换，请保留原始备份。
- **模型配置**：可以在渠道与模型设置中检查模型协议、主备组合和输出预算。
