# AIO Hub 0.7.0-r.1

本次更新汇总自上次发布的 **0.6.6-r.2** 以来的累计改动。期间部分版本因 CI/CD 配置问题未能发布，这里合并介绍这段时间新增的功能、体验改进与修复。

## 更新重点

- **知识体系重构**：思绪（Recall）与知识文档（Knowledge）分开管理，新增检索管线、资料工作台与旧数据迁移引导。
- **对话与模型配置增强**：支持斜杠命令、自定义工具栏、按用户回合压缩上下文，以及虚拟渠道主备组合。
- **子智能体与后台任务**：支持任务派遣、进度查看、追加指导、停止任务与跨窗口同步。
- **Git 工作台扩展**：新增分支泳道图、仓库全景、文件与内容搜索、媒体差异预览，以及统一标签创建与推送。
- **多媒体工具升级**：媒体生成支持全局任务队列，FFmpeg 新增序列帧合成，字幕 OCR 支持本地视频离线识别。

## 知识资料与思绪检索

- 原知识库拆分为「思绪（Recall）」与「知识文档（Knowledge）」，分别管理记忆条目和来源文档。
- Recall 使用 SQLite 持久化，支持语义、标签与关联联想等多种候选召回，提供检索管线预设、阶段编辑、评分与运行诊断。
- Knowledge 新增资料工作台，支持文件导入、目录来源同步、持久导入任务、分块与向量化、文档标签和检索过滤。
- 聊天支持显式引用资料；智能体可通过已授权的检索工具查询资料，知识库访问支持全局开关。
- 嵌入模型增加身份与向量空间配置，便于确认向量复用条件，降低切换模型后混用向量的风险。
- 重做备份与恢复格式，兼容旧版思绪备份，并支持将旧版思绪备份转换为 Knowledge 文档。
- 新增旧数据检测、迁移确认、执行进度与结果报告；迁移后默认保留旧目录，清理操作需单独确认。
- 修复删除资料后的全文索引残留、数据变更后检索缓存失效，以及资料库路径随数据目录迁移的问题。

## LLM 对话

- 输入框支持 `/` 斜杠命令、拼音检索与分组快捷操作。
- 输入工具栏支持自定义布局、排序与右侧状态显示；输入面板可展开、收起，并可设置重复点击时的行为。
- 新会话草稿支持持久保存与刷新恢复，新增工具栏新建会话入口。
- 支持单会话完整 JSON 导入与导出，携带关联附件和上下文参数。
- 消息支持排队、等待、生成与停止控制；增加自动重试 HTTP 状态码白名单。
- 上下文可按用户回合压缩，改进连续压缩时旧摘要的继承与展示。
- 可选将 VCP 上游响应拆分为多个消息节点，默认关闭；补齐分段消息的推理状态与耗时统计。
- 消息用量展示补充缓存命中信息，发送前图片 Token 预估考虑压缩与缩放结果。
- 优化长会话虚拟列表、阅读位置保持、气泡操作栏与工具调用展开布局；批量会话管理支持内容搜索与高亮。
- 修复会话保存、删除与恢复的一致性，加载时可修正意外中断的生成状态；流式响应中断后保留已接收内容。
- 修复消息重试受父节点角色限制、分段消息与排队消息分支冲突、话题自动命名触发时机，以及消息底部裁剪等问题。

## 模型、渠道与参数

- 渠道支持原生导入导出、New API「复制连接信息」导入，以及多格式模型 ID 批量添加。
- 支持模型执行协议的手工分配与探测结果应用，聚合渠道可配置默认协议路由。
- 新增虚拟渠道组合，统一管理主备模型执行与回退；下游工具保留显式模型绑定。
- 更新模型元数据规则、预设和能力识别，模型刷新前可预览变化；增加智能体模型参数与上下文配置页。
- 统一输出预算，并按模型能力过滤采样参数，减少不适用参数造成的请求失败。
- 接入 audio.cpp 本地音频渠道与专用语音转写端点，补充 OpenRouter 图像、视频、语音及 Decisions 协议适配。
- 增加 TypeSafe AI System One 决策渠道，并更新 DeepSeek、Claude、GPT、Gemini、GLM、Agnes 与 Jev 等模型适配。
- 修复 Azure 渠道运行时适配、配置导入误报，以及 Key 健康状态与连接测试行为不一致的问题；凭据全部不可用时给出明确错误。

## 智能体、子智能体与工具审批

- 新增子智能体交互工具与内置子智能体，按需提供可用能力，并支持并发与调度配置。
- 后台任务中心支持任务派遣、状态查询、追加指导与停止操作；主会话展示关联任务卡片和真实发送者。
- 伴生视图可查看后台任务上下文与实时进度，任务状态支持跨窗口同步。
- 工具审批支持 JEV 决策模型与普通 LLM 审批引擎，可按配置自动处理风险明确的请求，并将需要判断的请求交给用户。
- 后台任务接入工具审批；人工审批默认持续等待，支持配置超时，并在会话销毁或断线时清理待处理请求。
- 智能体资产支持短描述生成与批量补全，卡片增加描述与悬浮提示；修复打包导入、升级恢复和覆盖更新时的名称保留。
- Skill 概览采用双栏布局，集中展示说明、脚本与权限，改善嵌套滚动体验。
- 加固文件路径沙箱、VCP 文件传输、工具策略修改确认与脚本执行边界。

## Git 工作台

- 新增仓库全景概览、分支泳道图与工作区文件名、内容搜索。
- 支持查看提交文件变更、提交详情与远端跳转；差异视图增加导航、未更改区域折叠和首处改动定位。
- 提交与暂存差异支持图片、音频等媒体预览；支持预览标签页与 Alt 临时预览。
- 补齐右键操作，区分未跟踪文件的删除与放弃操作，增加更改总览与打开仓库目录入口。
- 每个仓库可配置 AI 提交提示词、提交语言与外观颜色；生成提交信息改用差异内容，并支持中止生成。
- 新增统一标签创建与推送弹窗。
- 修复仓库拖拽排序、历史刷新时列表消失、差异编辑器销毁与分支加载问题，移除 HEAD 历史统计的 5,000 条上限。

## 媒体生成、转写与网页提炼

- 媒体生成支持全局并发任务队列与自动清理，新增任务列表视图切换。
- 新增多模态快捷提示词库与光标位置插入；生成时可继续编辑草稿，附件随会话保存，输入框支持展开与收起。
- 提示词优化支持携带参考图，视频与音乐任务可展示上游轮询进度，结果下载支持独立超时设置。
- 改善重新生成、取消、失败详情与资产导入后的刷新，修复部分任务长期停留在处理中或入库中的问题。
- 转写增加模型拒绝与异常输出提醒，清理复读、占位行和额外说明，修复总开关与活跃任务过滤行为。
- 网页提炼新增 Jina 云端提取、DeepSeek 搜索与网页抓取，支持自动选择 DeepSeek 渠道；引入 Defuddle 提取并增强文档转换，接入统一代理配置。
- 工具可按需读取和发送本地媒体，聊天附件支持更多媒体占位形式。

## 视频、字幕与图像工具

- **FFmpeg**：新增序列帧合成工作区，支持刷新与拖入；简单模式可选择 CPU 或 GPU 编码。增加原始分辨率预设、片段裁剪、关键帧吸附和积木式自定义参数编辑，完善单文件进度、输出命名与覆盖保护。
- **实时字幕 OCR**：新增本地视频离线识别工作台，支持字幕行内编辑、时间轴吸附、监视器操作与区域预览；屏幕 OCR 增加图像滤镜和原图对比，改善多实例状态与截图稳定性。
- **色彩整理**：支持目录扫描、批量图片与 SVG 代表色分析、缩略图筛选和自定义分类归档；亮度阈值可设置 1–4 档，并支持拖拽微调与预设管理。
- **画板**：新增星形工具、形状绘制快捷键与 PNG 导出到剪贴板。
- **文档预览**：增加 WPS 与 OpenDocument 格式支持。

## 文件、自动化与系统体验

- 本地文件操作增加复制、移动、重命名、元数据读取与搜索，完善规则编辑和实时审计；长路径错误提示更简洁。
- 目录搜索增加资源限制与完整取消流程；符号链接搬家增加空间、权限预检与事务式回滚。
- 数据筛选增加纯文本模式，支持随机删行、按目标行数随机保留和按关键字保留。
- 窗口自动化使用中心坐标系，支持前台、后台两种键鼠操作模式。
- Token 计算器支持导入 ZIP、TAR、TAR.GZ 格式的 Hugging Face tokenizer，增加 DeepSeek V4.1 视觉输入估算。
- 主页新增最近使用工具与可拖拽快捷入口；设置页调整为分组两级导航。
- Windows 安装器支持自定义数据目录，重新安装时展示已安装版本与待安装版本。
- 版本说明支持历史浏览、搜索与当前版本识别；通知中心支持分页加载。
- 改善主题、弹层焦点、Escape 关闭、通知层级和工具可见性设置的保存；修复 Windows 打开文件所在目录失败与日志滚动丢失。
- 富文本渲染增强工具请求、转义围栏、附件卡片和主题变量兼容，缺失图片显示带资源信息的占位提示。
- 插件增加 Sidecar API v3、结构化诊断与平台验证，改善进程重启后的状态隔离。

## 升级前请留意

- 建议先备份重要会话、智能体和知识数据，再从 0.6.6-r.2 升级。
- 检测到旧知识数据时，请按迁移引导完成确认与校验。旧目录默认保留；确认数据完整后，可在清理步骤回收空间。
- 将旧版思绪备份转换为 Knowledge 文档属于单向转换，请保留原始备份。
- 升级后如需调整模型协议、主备组合或输出预算，可在渠道与模型设置中检查对应配置。
