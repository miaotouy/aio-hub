# AIO Hub 0.7.0-r.2

本次更新汇总自 **0.7.0-r.1** 以来的改动，重点完善预设消息组合、聊天编辑与分支操作、富文本渲染，以及 Git 分析和媒体生成工作流。

## 更新重点

- **预设消息组合**：一条消息可由多个片段拼接，每个片段可保存多个版本，支持勾选、排序、切换版本和完整正文预览。
- **聊天编辑与分支**：消息工具栏支持自定义布局，高级消息编辑器支持保存到新分支，会话可从文件重新加载。
- **富文本渲染**：修复 Markdown 表格、列表、代码围栏与引用等解析问题，降低长列表流式更新的卡顿和解析器内存开销。
- **Git 分析扩展**：支持读取 GitHub 公开仓库，新增工程指标与 AI 版本说明、演进摘要生成。
- **媒体生成体验**：生成结果可直接加入参考图，支持批量拖入参考图，并可选择提示词优化是否使用参考图片。

## 预设消息与上下文

- 智能体预设消息支持在普通正文与组合编排之间切换。组合编排保留片段顺序，每个片段可设置名称、启用状态和多个正文版本。
- 支持拖动排序、切换当前版本、设置片段连接符，并预览拼接后的完整正文；批量管理列表同步展示当前组合的正文摘要。
- 组合消息接入 Token 统计、聊天上下文注入、来源映射与导入导出，宏在片段拼接完成后统一处理。
- 编辑器补充草稿离开确认、保存冲突检测与结构撤销；切回普通正文前会提示确认拼接结果及其他版本的移除。
- 桌面端与移动端使用共享的组合规则，移动端同步提供组合编辑、正文转换、预览和聊天注入。
- 上下文分析器的宏调试视图新增详情弹窗，可查看完整名称、参数、预览值与表达式。

## LLM 对话

- 消息工具栏支持搜索操作、拖动或箭头排序、常驻与收纳切换，以及恢复默认布局；布局保存后同步到分离窗口。
- 支持从工具消息重新生成助手回复，便于沿工具执行结果继续尝试。
- 高级消息 JSON 编辑器新增「保存到分支」，可将角色、正文、元数据和附件等编辑结果保存为新分支，并支持撤销与重做。
- 会话菜单新增从文件重新加载，可在外部工具修改会话文件后刷新消息树与列表索引。操作需要确认，并在生成、排队、写入及并发编辑期间保护现有数据。
- 修复气泡消息宽度限制失效，统一聊天列表与截图中的布局表现。
- 改进消息树物理布局，内容或尺寸变化时延续节点位置与运动状态；显式重置时重新布局。
- 操作历史面板改为锚定工具栏按钮，并根据窗口边界调整位置与尺寸。
- 优化消息操作栏的键盘焦点样式与弹层关闭后的显示状态。

## 富文本与 Markdown

- 修复代码围栏、列表归属与起始编号、引用链接、实体解码及行内 HTML 空格等解析问题。
- 改进表格分列，保留空单元格、末行内容及单元格中的行内格式；补齐跨流式分块的表格解析处理。
- 改进公式边界扫描、未闭合内容恢复与流式上下文同步，减少静态解析和流式完成结果之间的差异。
- 长列表流式更新复用未变化的条目和渲染子树，减少尾部增量到达时的重复渲染。
- 减少重复扫描、AST 索引重建与节点比较，降低解析器内部对象的响应式代理开销。

## Git 分析与提交

- Git 分析支持输入 `owner/repo` 或 GitHub 仓库地址，匿名分页读取公开仓库，并按需加载提交详情。
- 新增工程指标视图，展示代码新增与删除行数、代码流动量、热点文件和提交体积分布，同时提示统计数据覆盖范围。
- 新增 AI 洞察，可基于当前筛选范围生成版本说明或项目演进摘要，需要选择可用的 LLM 模型。
- GitHub 数据源采用只读模式，提交详情与导出适配远端仓库。
- Git 提交工具新增 Diff 自动换行开关，设置持久保存并应用于工作区改动、提交详情及主区域差异视图。

## 媒体生成

- 任务卡片与会话中的生成图片可一键添加到参考图输入，自动检查重复项和数量上限。
- 参考图输入上限提高至 16 张，支持批量拖入文件；实际请求仍需遵循所选模型的能力与限制。
- 结果图片增加预览按钮，键盘操作和触控场景也可访问预览及添加参考图操作。
- 任务列表根据可用宽度切换宽屏、折行和堆叠布局，并同步调整虚拟列表行高；参考图使用缩略图与数量角标展示。
- 提示词优化新增是否参考图片的开关，可用状态随模型视觉能力与翻译模式调整。
- 优化面板在宽屏下支持双列展示，应用优化结果时保留输入编辑器的撤销历史。

## 模型、渠道与通用体验

- 渠道添加菜单统一提供普通渠道与组合渠道入口。
- 模型身份与路由配置默认折叠，保存时保留已有设置；模型列表简化为单行标识，补充悬停详情。
- 思考参数按模型元数据中的协议能力判断，改善兼容渠道与模型别名下的参数处理。
- 修复调整智能体思考预算时意外覆盖输出上限的问题。
- 修正 Gemini 嵌入模型的能力匹配，避免继承聊天模型的视觉、音频与图片尺寸配置。
- 修复智能 OCR 全局粘贴监听与输入框、富文本编辑器的冲突；页面缓存期间暂停监听，返回后恢复。
- 修复顶部消息被全局弹窗遮挡的层级问题。

## 使用提示

- 含组合正文的智能体导出文件使用新版格式，跨版本交换时建议双方升级到支持组合消息的版本；普通正文继续兼容原有格式。
- GitHub 仓库读取使用匿名请求，访问频率受服务端额度限制。工程指标按已加载数据统计，可结合界面中的覆盖范围判断结果。
