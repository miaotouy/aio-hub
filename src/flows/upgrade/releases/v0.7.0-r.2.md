# AIO Hub 0.7.0-r.2

本次新增预设消息组合，减少相似提示词的重复维护；聊天支持将高级编辑结果保存到新分支，Git 分析可以直接读取 GitHub 公开仓库。另有生成图转参考图、消息工具栏自定义，以及 Markdown 长回复的显示和性能改进。

## 智能体预设消息

几套提示词只有局部设定不同，公共正文却要逐份修改。新增的组合消息可以将这些变体放在一起维护：

- **公共正文与局部版本**：将公共规则和差异内容拆成片段，公共部分只需维护一份；人设、文风等局部差异可以通过片段版本切换，附加规则通过勾选加入。
- **排序与预览**：片段支持拖拽排序和设置连接方式，可预览最终拼接的完整正文，并统计 Token 用量。
- **编辑保护**：增加未保存离开提醒、保存冲突提示和结构调整撤销。
- **跨端使用**：桌面端与移动端均可编辑、使用和导入导出组合消息。

## LLM 对话

- **自定义消息工具栏**：支持搜索操作、拖拽排序，以及设置常驻和收纳按钮；布局保存后同步到分离窗口。
- **高级编辑保存到分支**：在消息 JSON 编辑器中修改角色、正文或附件后，可用「保存到分支」保留原对话并尝试新走向；编辑支持撤销与重做。
- **从工具消息重新生成**：工具执行完成后，可以基于同一份工具结果重新生成助手回复。
- **从文件重新加载会话**：外部编辑会话文件后，可在会话菜单中重新加载，刷新消息树和会话列表。
- **消息树布局**：内容或尺寸变化时尽量保留节点位置，减少布局跳动。
- **操作历史面板**：改为贴近工具栏按钮展开，并适应窗口边界。
- **气泡布局修复**：修复宽度限制失效和截图布局差异。
- **操作栏交互修复**：修复键盘焦点和弹层关闭后的显示异常。

## Markdown 与富文本

- **长列表生成性能**：减少流式更新中的重复渲染，改善长列表生成时的卡顿，并降低长文渲染的内存开销。
- **表格显示修复**：修复空单元格、末行内容和单元格内格式丢失的问题，改善逐步生成过程中的表格显示。
- **公式显示**：改善公式在生成中与完成后的显示一致性。
- **Markdown 语法修复**：修正代码围栏、列表编号、引用链接和行内 HTML 空格等解析问题。

## Git 分析与提交

- **GitHub 公开仓库分析**：输入 `owner/repo` 或仓库地址即可读取提交记录，无需先克隆到本地。
- **工程指标**：新增代码增删量、热点文件和提交规模分布，查看改动主要集中在哪里。
- **AI 洞察**：选择提交范围和可用的 LLM 模型后，可生成版本说明或项目演进摘要。
- **Diff 自动换行**：Git 提交工具新增差异自动换行开关，查看长代码行时可减少横向滚动，设置会持续保存。

## 媒体生成

- **生成图转参考图**：任务卡片和会话中的生成图片可以一键加入参考图，继续调整提示词生成。
- **参考图批量导入**：支持一次拖入多张文件，输入上限提高至 16 张。
- **提示词优化参考图片**：新增图片参考开关，可选择是否让模型结合当前图片优化提示词；应用结果后仍可通过撤销恢复先前内容。
- **图片预览**：增加独立预览按钮，键盘和触控操作均可访问预览及添加参考图功能。
- **任务列表布局**：随可用宽度调整排列，参考图显示缩略图与数量。
- **提示词优化面板**：宽屏下支持双列展示。

## 模型、渠道与其他修复

- **渠道添加入口**：菜单集中提供普通渠道和组合渠道。
- **模型列表**：简化单行展示，悬停可以查看详情。
- **模型高级设置**：默认收起身份与路由配置，减少列表中的信息干扰。
- **思考参数**：改善兼容渠道和模型别名的参数处理，修复调整智能体思考预算时意外覆盖输出上限的问题。
- **嵌入模型识别**：修正 Gemini 嵌入模型误用聊天模型能力配置的问题。
- **宏调试详情**：上下文分析器可以查看宏的完整名称、参数、预览值和表达式。
- **智能 OCR 粘贴**：修复全局监听干扰普通输入框和富文本编辑器的问题。
- **提示消息层级**：修复顶部消息被弹窗遮挡的问题。

## 使用与兼容提醒

- **组合转普通正文**：转换仅保留当前拼接结果，停用片段和其他版本会被移除，操作前请保留需要的内容。
- **智能体分享**：含组合消息的导出文件使用新版格式，请确认接收方版本支持组合消息；普通正文沿用原有导出格式。
- **GitHub 数据范围**：公开仓库采用匿名只读访问，受 GitHub 请求额度限制；工程指标按已加载的数据统计，请留意覆盖范围。
- **参考图数量**：单次请求可用的图片数量取决于所选模型的限制。
- **优化时参考图片**：开关是否可用取决于模型视觉能力和当前翻译模式。
