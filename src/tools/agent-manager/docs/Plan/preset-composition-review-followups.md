# 预设消息合并组：审查后续

> 更新：2026-10-25
> 状态：已处理条目与验证记录见下文
> 核对口径：沿现有界面、注册工具和导入入口确认可达性；孤立函数样例须同时具备实际调用路径。

## 已处理

### 1. 后台工具保存预设时，侧栏配置修改可能被覆盖

- 实际风险：已注册的 `edit_preset_composition` 工具进入 `agentStore.savePresetMessage`，执行期间侧栏模型参数仍可修改。修复前，保存完成后的整份快照回写会把温度从 0.9 恢复成旧值 0.2。
- 触发条件：工具目标与侧栏 Agent 相同，参数更新发生在读取磁盘快照后、内存回写前。
- 排除路径：消息编辑弹窗遮挡侧栏，保存期间禁止关闭；同一窗口“点保存后再操作背后的参数”缺少可达路径。多窗口并发仍单独核对，当前队列限于同一窗口。
- 修复：普通单体持久化、预设保存和删除按 Agent ID 共用写入队列；预设保存按字段合并等待期间的本地修改，消息列表按 ID 合并。异步 Token 元数据变化保留，新正文同时保留。后续普通保存从当前内存取快照。
- 验证：回归测试覆盖磁盘读取与写入两个等待阶段的参数修改、其他消息更新、同一消息 Token 元数据更新、磁盘独立字段修改、正文版本冲突、写入失败及重试；检查内存和最终磁盘结果。

### 2. 单选组复制后的启用约束

- 实际路径：对已启用单选组的当前消息点击“复制到下方”，修复前会保留两个启用成员，下一次发送被运行时校验拒绝。
- 同类入口：新增消息选择已有单选组，或把多个成员已启用的多选组改成单选组。
- 修复：复用 `reconcilePresetGroupSelection`。复制保留原选择、副本停用；新增或移入启用消息时选中该成员；改成单选时保留首个启用成员。关闭组时同步约束恢复选择，重新启用后恢复至多一项。界面及 Store 单体保存均接入。
- 验证：单测覆盖复制、加入、改模式与关闭后的恢复；Store 测试核对改组时其他成员同时停用并写盘。真实 Tauri 窗口中点击复制后，原成员保持选中，副本未选中，保存成功。

### 3. 原生 Agent 导入改写正文

- 实际路径：正常原生导出、导入经 `sanitizeImportedAgent` 清洗时，修复前统一执行酒馆宏转换，把 `<description>内容</description>` 改成 `{{description}}内容</description>`。
- 修复：原生清洗仅校验和迁移正文结构，普通正文、公共片段及未选中备选原样保留。酒馆格式继续在解析入口完成宏转换。
- 验证：实际 JSON 文件预检、提交链路覆盖 XML 标签、宏大小写、换行、空白与未选中备选；另用酒馆角色卡验证原有宏转换继续生效。

### 4. 合并消息正文工具栏少于普通消息

- 实际影响：编辑合并消息时，普通工具栏被隐藏，片段区原先仅提供插入宏。手动输入和 Monaco 自身快捷键仍可用，此项按编辑体验改进处理。
- 修复：新增共用 `PresetBodyToolbar`，普通正文及片段正文统一提供宏、变量、检索、复制、粘贴和覆盖；绑定当前片段或备选的编辑器实例。切换备选后，旧工具栏尚未完成的异步剪贴板读取会被丢弃。剪贴板改用项目既有 Tauri 接口，文本预览复制同步复用平台写入。
- 验证：真实 Tauri 窗口中向当前备选插入变量与 Recall 占位符并保存，核对公共正文和另一备选保持原样；从另一备选复制后粘贴至当前备选成功。完成工具栏布局截图走查。

## 后续追加处理

### 5. 单选组校验错误无法定位到具体组

- 实际影响：同一 Agent 存在多个单选组时，发送前的运行时校验只提示“单选消息组存在多个启用项”，用户需逐个组排查。
- 修复：`normalizePresetGroupState` 接受组的可选名称，错误文案改为 `单选消息组「{名称或 ID}」存在多个启用项`。
- 验证：核心包测试断言错误包含组名。

### 6. 共享组合包未接入根级检查与测试

- 实际影响：`@aiohub/agent-preset-core` 自带 `check` 与 `test:run`，但根 `check:packages` 与 `test:all` 未调用，核心编译逻辑没有 CI 回归网。
- 修复：新增根脚本 `check:agent-preset-core`、`test:agent-preset-core`，并入上述两个聚合入口。
- 验证：`bun run check:agent-preset-core`、`bun run test:agent-preset-core` 均为 13 项通过。

### 7. 移动端组合界面未接入既有 i18n

- 实际影响：移动端 agent-manager 已使用 `registerToolLocales` 注册 `PresetEditor` 命名空间，但新增的组合编辑器与卡片组合分支直接硬编码中文，切换英文界面时中英混排。
- 修复：`PresetCompositionEditor`、`PresetMessageCard` 的组合分支与 `PresetMessageEditor` 新建入口改用 `t()`，参数化文案使用命名插值；两个语言包补齐 47 个键。
- 验证：键一致性检查确认三个组件使用的全部键在两份语言包中均存在，`en-US` 无残留中文；移动端 324 项测试与生产构建通过。

### 8. 保存期间继续编辑的草稿被误标为已保存

- 实际路径：消息编辑器按 Ctrl+S 或 Ctrl+Enter 保存后，在异步写入完成前继续输入。原实现提交旧正文，完成后却按当前表单设置保存基线，后续关闭跳过草稿提示。
- 修复：提交时深拷贝消息并记录对应的表单快照；完成后只推进该快照的保存基线。等待期间的新编辑继续保留草稿状态，保存并返回操作也会保留编辑器。
- 验证：组件测试分别覆盖两种快捷键；确认写入旧快照、新正文仍触发离开提示，第二次保存提交新正文后关闭。

### 9. 组合卡片保存回填覆盖最新单选状态

- 实际路径：侧栏组合卡片 A 保存片段时，切换同组消息 B。Store 已合并最新选择，父组件随后回填旧 A 快照并重新协调单选状态，导致选择丢失。
- 修复：提供持久化回调时，由 modelValue 同步保存后的权威状态；本地草稿模式继续替换消息并向父级同步。
- 验证：组件测试覆盖保存等待期间切换消息，检查最终 A 停用、B 选中；另核对本地草稿模式仍发送更新事件。

### 10. 原生预设文件与剪贴板导入改写正文

- 实际路径：原生预设导出后再次导入，或单条组合消息通过剪贴板粘贴，正文仍经过酒馆宏转换，XML 标签与宏大小写发生变化。
- 修复：原生 JSON/YAML、原生预设剪贴板及单条消息配置保留原文；酒馆提示文件继续在对应解析入口完成宏转换。
- 验证：实际导出与文件导入链路覆盖 JSON/YAML、预设剪贴板及单条组合消息粘贴，检查公共正文与未选中备选；酒馆提示文件测试继续核对宏转换结果。

### 11. 导入路径丢弃组状态归一化结果

- 实际影响：`normalizePresetGroupState` 返回新数组，但桌面导入清洗、独立预设导入、配置工具导入以及移动端导入均丢弃返回值。停用组中的成员在持久化后仍保持启用，与编辑器内切换组时的状态不一致。运行时注入仍会强制关闭，因此问题限于持久化状态。
- 已确认位置：`agentImportService.ts`、`agentManagementService.ts` 两处、`usePresetImportExport.ts`、移动端 `PresetMessageEditor.vue` 与 `useAgentImporter.ts`。
- 修复：各调用点接回返回值并写回消息列表。
- 验证：导入服务测试新增停用组成员导入用例，确认成员保存为停用。

### 12. 撤销结构调整覆盖后续正文输入

- 实际路径：取消片段参与或移动片段后继续输入正文，再撤销结构调整，旧实现直接回填整份快照，丢弃后续输入。桌面组件回归已在修复前复现，无需并发或特殊时序。
- 修复：共享包按稳定 ID 恢复结构并保留当前正文与名称，两端复用。删除项恢复删除前的内容；单版本与多版本片段采用同一结构，撤销版本增删后仍按稳定 ID 保留正文。新增项随创建操作的撤销移除。
- 验证：桌面覆盖连续撤销参与及排序，移动端覆盖参与撤销后的正文与名称保留，共享包覆盖备选正文、名称、删除恢复及版本增删。
