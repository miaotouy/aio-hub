# 消息内部组合交互设计

> 更新：2026-10-24
> 状态：已接入业务；条目列表统一承担多选，条目内部保留单选版本
> 关联：[数据与上下文接入方案](./preset-message-composition-draft.md)、[审查记录](./preset-composition-review-followups.md)

## 0. 组合工作区

单条消息由有序片段组成。每个片段统一保存版本列表和当前使用版本，默认创建一个版本；只有一个版本时直接承担正文，之后可随时增删版本。片段列表通过勾选控制参与状态。外层角色和注入配置沿用原消息，内部编排宿主正文。列表与编辑入口统一使用“组合消息”。

- 创建入口统一为“添加片段”。条目与版本均支持可选名称和正文预览。
- 每个条目左侧提供勾选框，控制是否参与正文拼接；取消勾选时保留正文与单选状态。
- 点击条目切换编辑对象，点击勾选框只调整参与状态。版本标签同样只切换编辑对象，“选入此项”切换当前版本。
- 单选通过稳定 ID 指向一个版本，可清空选择；所有参与条目按列表顺序拼接，连接方式在组合层统一配置。
- 编辑器底部提供“完整正文”预览，跟随条目勾选与单选状态更新。

## 1. 消息卡片

组合消息复用普通消息的 `PresetMessageCard`，沿用相同的背景、边框、间距、字体、拖拽柄、角色图标、编辑按钮与启停控件。完整列表中的复制、粘贴、分组与删除也通过同一卡片提供。

宿主保留消息名称。卡片默认折叠，标题操作区提供展开/收起按钮，折叠时显示内容块数和当前正文摘要；点击摘要也可展开。内部条目左侧显示勾选框，正文展示名称与预览；单选组额外提供左右切换与“当前位置 / 总数”。移动端复用卡片既有展开状态，展开后显示全部条目与参与勾选。折叠只改变展示。

```text
⠿ ⚙ VCP 系统                         编辑  开
    <<<[ROLE_DIVIDE_USER]>>> …
    {{AIOgugu}}                   ‹ 1 / 2 ›
    AIO 与 VCP 的生态关系 …
```

- 点击卡片标题或编辑按钮，打开现有预设消息编辑弹窗。
- 点击片段预览，打开同一弹窗并定位到该片段。
- 第一项禁用左箭头，最后一项禁用右箭头；空选显示“— / 总数”，可用右箭头选入首项。
- 条目勾选和左右切换即时保存，成功后更新预览；失败时保留原状态，在卡片内显示错误与重试。
- 整条消息或所属消息组停用时，内部勾选和版本切换一起禁用；条目取消勾选时保留内容并禁用其版本切换，勾选框仍可恢复该条目，正文可继续编辑。
- 侧栏保留紧凑消息列表的布局，正文维护统一进入弹窗。

## 2. 编辑弹窗

沿用 `PresetMessageEditor` 的角色、宿主名称、所属组、过滤、注入、附件与保存入口，这些设置与普通消息一样常驻展示。“编辑 / 文本预览 / 渲染预览”切换同样可用，预览对象为按当前选择拼接后的正文。结构化正文由 `PresetCompositionEditor` 提供双栏工作区：

```text
┌ 片段列表 [3]        ↶ ┬ 片段 2      插入宏 │ ↑ ↓ ⧉ 🗑 ┐
│ ☑ ⠿ 1 公共规则          │ [1•][2][+] │ ← → ⧉ 🗑   当前使用：版本 1 │
│   公共规则在这里…      │ ┌──────────────────────────────────┐ │
│ ☑ ⠿ 2 风格  ‹1/2›   │ │ 正文编辑器                          │ │
│   {{AIOgugu}}        │ └──────────────────────────────────┘ │
│ [+ 添加片段]     │                                       │
├──────────────────────┴───────────────────────────────────────┤
│ 35 字符                                  连接 [原样|换行|空行] │
└──────────────────────────────────────────────────────────────┘
```

- 左侧每项展示名称与正文预览：左侧勾选框控制参与状态，序号、片段名称与版本切换在首行（未命名显示“片段 N”，单版本省略切换），正文预览占整行宽度并最多显示两行。整项可点击选中，拖拽柄负责排序，使用 `forceFallback` 和 `fallbackOnBody`，真实 Tauri 窗口验证；新增按钮固定在列表底部。
- 选中片段沿用资产卡片的半透明主色背景，随卡片透明度变化；轮廓使用主题主色。
- 右侧标题行承载片段级操作（插入宏、上移、下移、复制、删除）。所有片段在下方一行放置版本标签与版本级操作：标签右上角圆点标记当前使用项，左右移动对应标签的水平顺序，“选入此项”与“清空选择”位于同一行右侧。
- 新增入口直接创建含一个使用中版本的片段，片段与版本均可编辑名称；新增版本只改变编辑对象，当前使用版本保持原样。
- 正文复用既有代码编辑器与宏选择器；底部状态栏显示字符数、编译错误与连接方式（原样、换行、空行）。完整正文通过右上角“文本预览 / 渲染预览”查看。
- 工作区按自身宽度响应：容器宽度不足 680px 时改为上下排列。
- 保存成功后返回列表。`Ctrl/Cmd + S` 保存并停留，`Ctrl/Cmd + Enter` 保存并返回。
- 有未保存修改时关闭弹窗，提供放弃更改、继续编辑与保存并关闭；保存失败保留草稿。

## 3. 转换入口

单选消息组的组头提供“合并为一条消息”图标入口，打开转换预览。预设列表头部的“组合消息”按钮与“添加消息”相邻，用于直接新建组合消息。确认前保持原配置；应用时一次替换原成员并打开新宿主的编辑弹窗。

- 以成员卡片展示原消息的角色、注入、匹配与附件差异，被选为外层配置来源的成员高亮。差异与穿插提示合并为一条提示，确认勾选位于提示内。
- 成员之间穿插其他消息时，确认新宿主放在首个成员的位置。
- 成员本身是组合消息时，转换只保留其当前选中的正文，内部其他版本与停用片段不再保留；提示与上述差异合并展示，确认后才能应用。
- 建议切分按完整宏边界提取公共正文与差异正文，保留原始空白和换行。
- 消息编辑器常驻“内容形式：普通正文 / 组合编排”切换。选择组合编排即创建并选中一个片段，原正文保存在其首个版本中；空正文可直接填写。切回普通正文时确认仅保留当前拼接内容。
- 普通正文工具栏保留“提取为单选组”快捷操作；选区落在宏内部时先确认扩展范围。

## 4. 移动端

移动端同步支持名称、正文预览、条目勾选与组内单选，未命名版本按数字编号。片段列表与正文编辑采用页面内切换，继续复用移动端现有的消息编辑入口。合并正文作为“内容”字段的单张卡片呈现：列表为分隔行（左侧勾选框、序号、名称与版本选择、两行预览），编辑页标题栏放返回、片段位置与参与勾选框，片段级与版本级操作分为两行图标按钮，触控目标不小于 40px。

## 5. 本轮调整范围

本轮扩展单条消息内部的组合模型与卡片折叠，并保留普通消息的外层配置与卡片交互。保存并发、原生导入文本保持与单选组复制约束的后续工作记录在[审查记录](./preset-composition-review-followups.md)。
