# 屏幕实时 OCR 模式布局重构方案

> 日期：2026-09-12  
> 状态：Done / 已实施  
> 原则：基于当前屏幕模式原有的布局比例与高度（上方紧凑预览区 260px，下方字幕列表占满大半屏），精简顶栏、将右侧鸡肋编辑区替换为 OCR 配置面板，并在时间轴中提供行内编辑。

---

## 1. 核心设计与第一性原理

- **顶栏纯粹化**：最顶部仅保留全局模式切换（屏幕实时 OCR / 本地视频 OCR）及状态 Badge，不再塞入任何业务配置组件。
- **保持现有框架尺寸**：
  - 上方区域维持原有默认高度（~~260px，可上下拖拽调高，范围 180px~~600px）。
  - 下方字幕时间轴列表占据屏幕大半高度（全宽流式展示，直观高密度）。
- **上方左右分栏改造**：
  - **左侧（监视与滤镜区）**：承载 `LivePreview`（监控画面与控制按钮）和 `RegionFilterPreview`（滤镜前后对照与单帧试识别）。根据选区宽高比与容器宽度智能上下堆叠或并排排列。
  - **右侧（OCR 配置区）**：直接替换掉原本无用的 `ActiveSubtitleEditor` 大输入框，改为放 `MonitorConfig`（OCR 引擎选择及配置、图像滤镜预设与高级参数、采样频率、去重灵敏度等），与本地视频模式的 Inspector 保持一致。
- **下方字幕时间轴升级**：
  - `SubtitleTimeline.vue` 升级支持点击/双击单元格直接行内编辑，失焦或回车保存，`Esc` 取消。

## 3. 具体改造步骤

1. **改造 `SubtitleTimeline.vue`**：
   - 增加行内编辑交互：点击文本单元格切换为编辑状态，失焦或 `Enter`/`Ctrl+Enter` 触发保存并更新字幕，`Esc` 退出。
2. **重构 `RealtimeSubtitleOcr.vue` 屏幕模式**：
   - 顶栏移除所有业务配置项，仅保留模式切换器和状态徽标。
   - 上方右侧移除 `ActiveSubtitleEditor.vue`，挂载 `MonitorConfig.vue` 垂直面板。
   - 上方左侧优化 `LivePreview` 与 `RegionFilterPreview` 的自适应堆叠展示（宽高比横向时上下堆叠，竖向或宽容器时自适应），保证预览清晰。
3. **架构文档同步**：
   - 更新 `ARCHITECTURE.md` 说明。
4. **前端类型与编译检查**：
   - 执行 `bun run check:frontend`。
