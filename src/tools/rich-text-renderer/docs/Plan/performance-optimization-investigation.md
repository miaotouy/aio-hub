## 1. 当前结论

主要压力集中在完整 buffer 的扫描与重复解析、Vue 组件及 DOM 数量、代码编辑器和其他重型节点的生命周期。下一轮围绕已经采到的开销推进，解析、渲染、原生进程和背景合成分别观察。

本页合并了旧轮次的重复分析，保留决策依据和待办。各轮命令、原始结果、规范差异与实现细节见 [规范与性能研究记录](markdown-conformance-and-performance.md)；整应用的真实会话与外观组合见 [内存工作负载矩阵](../../../../../docs/Plan/app-memory-workload-matrix.md)。

### 现有机制与剩余边界

- `RichTextRenderer.vue` 使用 V2 处理器与单树 AST Patch；AST 为浅引用，更新按 rAF 合帧。分词 Worker 之外的解析、diff、patch 和 Vue commit 仍在主线程。
- `MessageList.vue` 对消息整行使用 `content-visibility: auto`；`MessageContent.vue` 冻结离屏消息配置，深层 HTML 预览可冻结 iframe。CSS 跳过布局后，组件和 DOM 仍可常驻。
- renderer 内部块级 `content-visibility` CSS 保持注释状态。更细的长消息挂载需要高度缓存和滚动锚点。
- 原有代码块逻辑提前 600px 初始化 CodeMirror，完成后一直保留。单个 4,000 行代码块只有一个编辑器；1,248 个短代码块的全篇滚动则会让编辑器从 5 个增长到 1,248 个，回到顶部仍保留。主线程 GC 堆约 112 → 142 MiB，卸载后约 48.7 MiB。
- 短代码块外围约 37 个元素、6 个按钮。固定围栏样本约有 10.1 万 DOM 和 1.5 万监听器；CodeMirror 之外的工具栏和组件数量同样需要处理。

### 当前轮实施边界

代码查看器离开 600px 预加载区后等待 2 秒，再将完成态编辑器回退到轻量源码；保留当前高度和标量 UI 状态。获得焦点或参与文本选区的编辑器保持可用，进行中的输出继续更新。KeepAlive 停用时释放编辑器，重新激活或滚回时由当前内容重建；延迟语言加载只作用于发起请求的那一代视图。显示 CodeMirror 时卸载隐藏的 `PreCodeNode`，减少重复全文和行号 DOM。

HTML iframe 冻结沿用既有策略。会话树、消息原文、模型上下文和持久化内容保持原样。短代码块工具栏精简与整消息虚拟挂载继续留在后续项。

### 本轮对照方式

- 同一冻结匿名语料、性能构建通道、视口和 WebView2，先采旧二进制，再重建后采新二进制。
- 先以 `branches` × 特效关闭 / 强玻璃配置做各 2 次往返，观察代码块、页面 CodeMirror（含聊天输入区）和源码回退数量；增加 `scroll-rest` 阶段区分滚动中的预热与静置后的释放。
- Private / WS、页面 heap、DOM、编辑器与实际滚动位置一起记录；自然 GC 与末轮强制页面 GC 分开报告。
- 本轮独立轮数较少，结果用于判断实现方向。配置效应、持续增长和更广泛收益需追加独立轮次；完成态数据写在下节。

## 4. 本轮结果（2026-10-27）

组件行为测试覆盖源码与折叠 / 选区 / 内部滚动恢复、流式与短时往返保护、KeepAlive 释放恢复、过期语言加载隔离，以及焦点 / 文本选取保护。断言通过实际只读编辑器和 DOM 交互验证；界面几何和整体内存另走真实窗口。

同一冻结语料、相同阶段参数，旧版与改后各运行 `branches` × 特效关闭 / 强玻璃，共 4 个独立进程案例，每个进程往返 2 次。全部完成，52 个检查点有效，图表 / 图片错误计数为 0。真实截图检查了聊天框架、表格和代码区域。性能构建通过前端类型检查、Vite 生产构建及 Rust release；相关 4 个测试文件共 13 个用例通过，其中 5 个保护本轮代码查看器行为。

## 5. DOM 驻留归因补充（2026-10-27）

已完成 [聊天 DOM 驻留归因与下一轮方向](chat-dom-retention-investigation.md)。复核确认 UTF-8 读写正常；旧语料的随机词替换破坏了部分 VCP 扩展协议识别，可读语料改为保留正文并定向脱敏，两种模式结果分开记录。

可读 `branches` 仍挂载约 7.4 万消息区节点，列表 / 表格 / 图表分别约 2.2 万 / 1.0 万 / 0.84 万。返回首页 GC 后页面堆约 223 MiB；切换空会话并 GC 后约 71 MiB，全局 DOM 约 10.9 万 → 1.4 万。document 中还有约 2.57 万 popper 子树节点。现有 KeepAlive 和持久菜单是可定位的驻留来源，长期泄漏另需趋势证据。

近期实施结果（分轮口径见专项记录）：

- 翻译 / 更多菜单按需挂载，变量详情使用稳定宿主；停用页回收富文本显示树。该阶段单轮首页 GC 页面堆约 185.2 → 110.3 MiB，阅读位置、代码显示状态与草稿恢复通过。
- Mermaid 共享配置和串行渲染，按高度快照与阅读区域恢复屏外图表。最终对照的返回后长任务累计 1,715 → 827ms，可见图表、完整浏览、窄窗与缩放恢复通过；自然堆受 GC 时点影响较大。
- 代码块工具栏改为按交互创建并复用提示层，保留全部按钮。固定 branches 活动页 GC 页面堆 190.13 → 176.61 MiB，监听器减少 2,479 个；复制反馈、键盘、字体 / 换行 / 展开与 HTML 预览已在真实窗口复核。

按调用帧复核，vendor-editor 热点实际来自 Vue 的属性合并、组件初始化与渲染。下一重点是组件挂载、几何读取和活动页历史内容挂载；流式增量解析沿原路线独立推进。继续复核 rich-text 选样与实际表格数量的差异，完整数量、口径与本地产物见专项记录。

## 6. 后续路线与复现入口

### 计算管线

稳定区扫描仍需块级源码锚点、尾块回看和全局引用上下文。此前直接拼接稳定前缀的原型遇到尾部换行归属随输入变化的问题。保留单树 AST diff，避免拆容器导致长列表或引用视觉断裂。解析背压先量化预处理、边界扫描和 patch 调度，再决定频率；聚合文本应减少重复读取和中间数组，留意大列表上的缓存额外成本。图片列表的全 AST 扫描可另评估 patch 驱动。

### 重型节点

Mermaid 关注 pending 阶段频率、最后成功 SVG 与 stable 终渲染；HTML 关注 stable 后挂载、CDN 本地化缓存和沙箱生命周期；KaTeX 关注内容 / displayMode 缓存，当前固定采样的 149 个组件在流式中无重复更新。长代码流的 append-only 插入与编辑器回收分别对照。节点级异步就绪需与 AST 完成分开计时。

### 正式入口

- 规范、固定语料和细节记录：[markdown-conformance-and-performance.md](markdown-conformance-and-performance.md)。
- 计算计时 / CPU：`bun run rich-text:bench`、`bun run rich-text:profile`。
- 真实组件时延 / 内存：`bun run rich-text:performance:tauri`、`bun run rich-text:memory:tauri`；固定代码全篇滚动加 `--scroll --filter '^code:'`。
- 完整聊天和外观配置：`bun run perf:memory`，参数与采样定义见 [应用内存矩阵](../../../../../docs/Plan/app-memory-workload-matrix.md)。
- 回收定位：`bun run rich-text:heap:compare`，组件弱引用、Worker 和原生进程分别核查。


### 文本节点层级与后续挂载范围（2026-10-28）

完成 Vue 热点归因后，文本和附件预览合并到 TextNode 的同次渲染，减少每个文本片段额外创建的函数组件。同口径可读 branches 活动页 GC 页面堆 176.64 → 170.23 MiB；56 份渲染器、87,812 个正文字符及 DOM / 监听器数量持平。底部返回双 rAF 652.4 → 654.1ms，当前收益集中在驻留堆；原生附件交互、单测、类型检查与构建已复核。下一轮推进活动页历史显示树回收，具体边界和本地产物见[专项记录第 13 节](chat-dom-retention-investigation.md)。
