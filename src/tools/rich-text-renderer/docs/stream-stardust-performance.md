# 星屑流式动效：原型与性能记录

日期：2026-10-30。

## 体验入口

- LLM 对话 → 聊天设置 → 渲染设置 → 开启「节点进入动画」→「流式文字特效」。
- 富文本渲染测试 → 选择「流式动效画廊」预设 → 选择轻盈或华丽档 → 流式渲染。

默认关闭。轻盈档使用短光带、细小菱形与星点；华丽档增加粒子数量、大小、飞散距离与存活时间。颜色跟随主题主色。正文继续使用现有平滑输出与 AST 渲染，特效负责新增文字附近的装饰编排。

## 实测方法

在独立开发实例的真实 Tauri WebView2 中，通过项目 Dev Control 连接测量实际 `RichTextRenderer.vue`。样本使用单个活动渲染器、V2 解析器和 StreamSource，保留平滑输出、80ms 节流及节点入场动画。每个批次自动滚动到新文字处。

机器为 AMD Ryzen 9 5900X；WebView2 为 Edge 156.0.4314.50。视口 1280 × 768 CSS px，DPR 1.5，采样的常见 rAF 间隔约 8.3ms。前端为 Vite HMR，Vue DevTools 的组件事件缓存按现有性能探针做法临时停用。

- 连续输出：954 个字符，每 70ms 交付 10 个字符，三种模式分别运行三轮，轮换顺序。
- 高速突发：15,900 个字符，每 16ms 交付 160 个字符，三种模式分别运行两轮，轮换顺序。
- 每轮结束等待余粒消散，核对最终正文，并再次等待以确认绘制计数停止。
- 帧间隔由独立 rAF 采样；特效回调耗时包含行框测量、画布分配和 Canvas 绘图命令提交；页面长任务使用 PerformanceObserver 观察。性能采样期间停止截图。

## 结果

帧间隔 P95 与特效回调耗时取各轮平均；粒子和最长帧间隔取各轮最大；超过 33.34ms 的帧间隔按全部轮次求和。单位为 ms。

| 场景     | 模式 | 帧间隔 P95 | 特效平均回调 | 粒子峰值 | 最长帧间隔 | 超过 33.34ms 次数 |
| -------- | ---- | ---------: | -----------: | -------: | ---------: | ----------------: |
| 连续输出 | 关闭 |        8.4 |            — |        0 |       16.6 |                 0 |
| 连续输出 | 轻盈 |        8.4 |        0.307 |       66 |       16.8 |                 0 |
| 连续输出 | 华丽 |        8.4 |        0.378 |      147 |       16.7 |                 0 |
| 高速突发 | 关闭 |        8.4 |            — |        0 |       25.0 |                 0 |
| 高速突发 | 轻盈 |        8.4 |        0.781 |       96 |       75.1 |                 1 |
| 高速突发 | 华丽 |        8.4 |        0.734 |      160 |       25.1 |                 0 |

15 轮的最终正文均与输入一致，结束后画布均已释放，绘制计数均已停止。页面错误和观测到的长任务数量均为 0。高速突发的轻盈档有一次约 50ms 帧间隔，说明突发输出仍有偶发抖动；该样本中三种模式的 P95 接近。

连续输出期间，关闭／轻盈／华丽三档的 CDP ScriptDuration 增量均值分别约为 109／286／353ms；特效会增加脚本工作量。高速突发期间对应值约为 56／116／127ms。该指标包含整个采样窗口的脚本执行，和特效回调的墙钟耗时属于不同口径。

本轮最大画布约 137 万像素，按单份 RGBA 像素数据估算约 5.2MiB。浏览器的额外缓冲、GPU 资源和整体进程内存需另行采样。绘图命令提交后的 GPU 光栅化耗时也需要专门的图形跟踪。

## 交互与资源检查

真实测试页中检查了深色与浅色主题、画布与祖先滚动裁剪区域的边界、鼠标穿透、正文原生选择、生成中切换系统减少动态效果，以及停止后的释放。选择到的正文为「夜幕落下」；系统减少动态效果开启后画布移除，恢复偏好后随新文字继续出现。

## 样本范围与后续方向

结果反映这台桌面机器的开发模式、纯正文和单活动渲染器场景。低功耗设备、多个回答同时生成、复杂公式与富媒体应在后续扩大样本时分别测量。

当前原型提供预置编排。下一步可针对突发输出增加自适应降档，并把图形形状、配色、轨迹与时间轴拆成可保存的特效预设。正文的逐字遮罩显现可作为独立效果扩展。

本轮原始结果、录屏及一次性采样脚本保存在 `.tmp/stream-stardust/`。实现与资源生命周期见 [渲染器架构](../ARCHITECTURE.md#710-流式文字装饰特效)。

## 扩展样式复测（2026-10-30）

新增几何碎片、花瓣轻舞、全息扫描和水墨晕染，连同原有两档星屑共六种预设。所有样式复用流式观察、可见区域裁剪和资源清理；绘制编排与资源参数集中在 `streamEffectStyles.ts`，两个设置入口复用同一组选项。

- 几何碎片：斜切线、实心与空心三角片，较快旋转并向外飞散。
- 花瓣轻舞：主题警示色的柔和花瓣，使用摆动轨迹和翻转缩放模拟飘落。
- 全息扫描：垂直扫描线、定位角标、像素短线和空心方块，位置按小网格移动。
- 水墨晕染：跟随正文颜色的半透明墨团，叠加扩散并逐渐变淡，深浅主题均保留对比。

同一真实 WebView2 刷新后，关闭、星屑轻盈与四种新样式分别测试两轮连续输出、一轮高速突发，共 18 轮。设备、开发模式、平滑与节流设置沿用前述条件。连续样本为 636 字符，每 60ms 交付 10 字符；突发样本为 9,540 字符，每 16ms 交付 160 字符。截图与录屏在性能采样前完成。

## 字色覆盖扩展（2026-10-30）

六种预设同步增加文字字形变色：星屑、几何和扫描采用主题主色，华丽星屑混合主题主色与警示色，花瓣采用警示色，水墨采用混合正文原色的淡染。覆盖按短色带错峰扫入，并在约 0.4～0.9 秒内退回原色。

使用 CSS Custom Highlight 的原生 Range 着色，复用已有 rAF；每个控制器最多保留 48 个覆盖范围和 16 档颜色。Range 记录文本与逻辑偏移，跟随 Vue 对 Text.data 的整体更新和 Text 节点替换重新定位，维持持续输出期间的变色范围；正文被重写时移除对应覆盖。系统减少动态效果、关闭、停用和销毁沿用原有生命周期。缺少所需浏览器能力时保留图形与粒子效果。

### 渐变尾部颜色修正（2026-10-30）

上一轮动态预览的尾部发暗：`::highlight` 中的 `currentColor` 受到祖先高亮继承影响，嵌套文字的混色目标偏离原本的正文色。现改为读取每个文字宿主的计算颜色，用明确的特效色与目标色进行混合，正文、标题和链接各自保留原有配色。

颜色按目标色及主题配色分组，每组 16 档，最多同时保留 8 组、128 个原生高亮和 48 个文字范围。最后一个文字范围释放后，相应色组即时注销；额外色组沿用原文字色。

真实 Tauri WebView2 采用深浅两种背景、正文与彩色链接，冻结在扫入起点、中段与 99% 位置共 12 个颜色样本。检查浏览器解析后的混合颜色及其 RGBA：覆盖期间 alpha 与原文字色一致，99% 位置的 RGB 到各自目标色的欧氏距离小于 14（8 位通道），清理后高亮注册归零。随后重新录制四种样式的完整测试页预览。验证脚本、样本和修正后 GIF 位于 `.tmp/stream-tint-tail-fix/`。相关 14 项测试通过，资源上限测试同时覆盖多色文字输入；类型检查和生产构建通过。


## HTML 文字接入（2026-10-30）

流式观察范围扩展至行内 HTML、HTML 块、通用 HTML 标签，以及纯 markdown-it 的 HTML 输出。整体 `v-html` 替换时对比新旧正文槽位，保留已有文字的覆盖位置，只触发新增尾部；代码、脚本、样式、表单与可编辑控件等继续走原有展示路径。

独立 HTML 预览通过 `useHtmlStreamStardust` 接入现有同源 iframe 文档，复用字色、粒子、动态效果偏好和清理机制。预览仍按原有一秒节流刷新；每次加载对比上一份正文快照，收集范围限制为 128 个 DOM 节点。导航前释放旧文档控制器，iframe 自适应高度变化时保留当前动画，宽度变化时清理并等待后续文字。画布定位值仅在变化时写入，避免稳定动画反复触发预览的高度测量。沙箱权限和 CSP 沿用原配置。

真实 Tauri WebView2 同时挂载两个实际 V2 渲染器，分别显示 HTML 标签与独立 HTML 文档，持续追加同一段正文。两侧均检测到正文高亮，完成后的文本与输入一致；高亮与画布释放，HTML 预览按钮点击正常，页面错误为 0。验证脚本、动态截图和结果保存在 `.tmp/stream-html-effects/`。

相关自动测试 28 项通过，覆盖四类 HTML 容器的增量文字、整体子树替换后的旧文保留、预览初始快照对比、自适应高度与宽度变化的清理边界，以及原有预览刷新生命周期和设置映射。类型检查与 Vite 生产构建通过。
